Configuration guidance
What is MCP?

The Model Context Protocol is the industry's common integration protocol for wiring external resources into an agent. It exposes tools and resource prompts on demand, locally or remotely.

Security note:

Never expose a root-privileged executor directly to an untrusted agent. Pair it with the three-tier approval rules.
