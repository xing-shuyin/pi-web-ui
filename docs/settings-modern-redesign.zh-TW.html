什麼是 MCP？

Model Context Protocol 是目前工業界統一的智慧體外部資源整合協議。它支援在本地或遠端按需暴露工具與資源提示詞。

安全提示：

嚴禁將包含 root 許可權的執行器直接暴露給非受信智慧體。建議配合安全審批規則三檔使用。

方案 5 · 專業 IDE 級Studio 全屏工作臺流 (Vercel / Notion 模式)：適合當專案生態過於龐大時（MCP、定時任務、子代理模板庫、DSH）。平滑切換為三欄式寬屏工作臺：左側導航、中間設定流、右側整合即時文件與執行態診斷，徹底擺脫 800px 彈窗的狹窄窒息感。
