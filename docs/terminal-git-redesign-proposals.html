终端下沉为底部抽屉，Git 升级为右侧检阅抽屉

现状：终端与 Git 都是全页 .view-pane 切页，看一行编译错误就把对话顶掉。 本方案把两类工具按真实使用姿势重新归位：终端 = 运行态（边聊边跑，底部可拖抽屉）； Git = 检阅态（边看 diff 边让 agent 改，右侧非模态宽抽屉）。手机端两者统一退化为全屏 sheet。

终端不再打断对话 diff 有宽度、上下文不丢 手机端不做上下分屏 xterm 实例常驻不重建 不是两个弹窗叠在聊天上

手机端

不做上下分屏；两个工具都退化为全屏 sheet，靠顶部把手下拉关闭

为什么手机不做分屏

  • 屏幕高度 ~740px，上下分屏后对话区只剩两三个气泡，比全页切换更差。
  • 软键盘弹出会再吃掉 40%高度，xterm 和输入框抢空间，fit() 会疯狂抖动。
  • 手机上终端的高频场景是「看一眼命令是否跑完」，全屏 sheet + 下拉关闭的心智成本最低。

手机端的三个新增

  • sheet 把手：顶部 34×4 的 grabber + 下拉手势关闭，替代全页左上角返回。
  • Git 变成全屏 sheet：顶部 segmented 切 Changes / History，文件列表 → diff 二级下钻。
  • tab 变横向 chips：多终端在窄屏用可滑动 chips，不再挤成一排小方块。

规格

尺寸、动效、语义色都从这里取，落地时不再临时拍数值

布局与尺寸

项桌面 ≥1100px平板 768–1100手机 <768
终端底部抽屉，180 / 318 / 70vh同左，默认 280全屏 sheet，64vh → 100dvh
Git右侧抽屉，480 / 672 / vw−380640，与右栏二选一全屏 sheet
与聊天关系终端挤压，Git 挤压（不遮挡）同左两者都覆盖
折叠态39px 条，tab 与入口仍在39px下拉即关闭

动效与手感

  • 展开/收起 height 220ms cubic-bezier(.22,1,.36,1)；拖拽中加 .dragging 关掉 transition，松手再开。
  • Git 抽屉用 width + opacity 挤压工作区，而不是 translate 滑入——滑入会盖住底部终端，两者同时打开时会打架。
  • 把手热区 9px，视觉只有 36×3；hover 变宽到 52 并染 accent——小尺寸但不难点。
  • 运行中用 2.2s 脉冲点，不用无限旋转 spinner（终端里已有输出，两个动效会打架）。
  • 全程只动 transform/opacity/height，不碰 top/left/width（Git 抽屉宽度除外，拖拽时它就是主任务）。

视觉规则

  • 层次靠背景差，不靠描边：--bg → --bg-elev → --bg-elev2 三档 + 1px --border-soft。
  • accent 只给三件事：当前 tab 下划线、主按钮、焦点环。其余全中性。
  • 语义色只标状态：M 琥珀 / A 绿 / D 红 / U 蓝，都用 15×15 圆角方块 + mono 单字母，不写全词。
  • 路径与数字一律 mono且 tabular-nums，diff 行号右对齐不跳动。
  • 圆角三档：外框 14 · 卡/抽屉 10 · chip/kbd 5–7。不出现 4px 以下圆角，避免“老后台”感。

信息架构重排（这才是“变好看”的关键）

  • 终端：旧版左侧 aside 同时塞了“命令列表 + tab 列表”，两层导航并列。新版把命令列表降级为按需浮层（Commands 按钮 / Ctrl+K），抽屉头只留 tab 与动作。
  • Git：旧版顶部 4 行按钮堆（分支、stash、branch、amend、blame…）。新版只留一行（分支 + fetch/pull/push + 关闭），其余收进 ⋯ 菜单。
  • 提交动作常驻底部：commit 是高频终点，不该在滚动区里随内容漂移。
  • Changes / History / Stash 变成 segmented，取代三个同等权重的按钮。
  • AI Bash 仍是折叠组，但用「组头 + 计数」表达，不再和用户 tab 视觉同级。

04

落地要点

按项目既有约束写，避免返工与守卫失败

必须守住的

  • xterm 实例常驻：折叠只 display:none，不卸载；否则 2MB 缓冲全量重放会闪屏。
  • 拖拽期间节流 fit：ResizeObserver 回调里判断 resizing，松手后补一次测量。
  • DeferredMount 语义：从 view==="terminal" 改成“抽屉曾经打开过”，首次打开才挂载。
  • 层级走 useOverlayZIndex()，不写死 z-index（overlay-stack 守卫）。
  • 底部安全区：env(safe-area-inset-bottom) 计入抽屉高度，别让最后一行被 Home 条盖住。
  • 入口保留：TopBar 的 tb-tab、左侧 dock、uiSlots 插槽全部保留，只是行为从“切页”变“开抽屉”。

容易踩的坑

  • 手机手势打架：已有 useSwipeDrawer 左右滑开侧栏；底部上滑必须限定在 grabber 区域，别抢全屏手势。
  • composer 被顶掉：抽屉展开后若把输入框挤出可视区，messages-behind-composer 守卫会挂；终端高度上限设 70vh 而不是 90vh。
  • Git 抽屉与右栏冲突：RightPanel 占右侧。规则定为「Git 打开时右栏自动折叠，关闭后恢复」——比两者并列更省宽度。
  • diff 全屏按钮：SCMPanel 内已有全屏 diff，在抽屉里保留为“拉满”逃生舱，避免小屏读 diff 痛苦。
  • 持久化：高度/宽度沿用 panelWidthKey 那套 localStorage 写法，键名如 pi-web-ui:term-drawer-h。
  • 减少动效：尊重 prefers-reduced-motion，抽屉直接切不滑。
