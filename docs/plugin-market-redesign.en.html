sftp sync service
Official built-in · version 1.4.0 · author: xing-shuyin

Capabilities and configuration manual

Project-level SFTP sync: configuration lives in .pi/sftp.json at the root. Diffs are computed up front, files transfer in parallel and can be stopped at any time. From the panel you can manually upload or download a single file or a whole directory tree, and native sftp tools are registered with the AI.
