PR-02 靜態檢查與實現 RUNNING
PI 原生 deepseek-flash 工作區: /code/git/yth-operation
💡 提示：支援快捷鍵 Esc 退出全屏或關閉；點選遮罩外部也可關閉。
方案架構 設計核心思想 解決“擁擠”的關鍵手段 適用工作場景 綜合推薦度
方案 1: 工作臺場景選項卡
(Workspace Tabs) 		資訊分層與專注。頂層將“實錄與插話”、“任務指令”、“契約審查”、“環境引數”解耦為獨立 Tab。 獨享 100% 寬度。長程式碼/終端輸出不再被左欄 500px 擠壓；看指令時也不受空日誌干擾。 深耕重度開發、多輪審查、終端命令排錯的綜合協作流。 ★★★★★ (強烈推薦·體驗最清爽)
方案 2: IDE 分屏與側欄摺疊
(IDE Split Pane) 		類似 VS Code 工作區。左側極窄引數大綱（可一鍵收攏），右側雙窗格或全寬。 引數微縮 + 彈性收縮。摺疊後中央區域獨享 ~95% 視域，適合需要隨時對照配置的使用者。 既要頻繁對照人設/契約、又要時刻盯著終端日誌的高頻除錯場景。 ★★★★☆ (操作習慣類似 IDE)
方案 3: 場景自適應手風琴
(Smart Accordion) 		單列自上而下順暢流式佈局，各個模組採用智慧摺疊手風琴卡片。 智慧感知狀態摺疊。執行態自動收起繁瑣配置只留 1 行摘要，自動撐大日誌區。 追求極簡線性互動、不想頻繁點選 Tab 的使用者。 ★★★★☆ (單列自然順暢)
方案 4: 全景三欄協同座艙
(3-Col Cockpit) 		三聯畫布局：[1. 輸入契約] ➔ [2. 指令與交付] ➔ [3. 實錄與插話]。 橫向三維拉伸。充分利用全屏與 2K/4K 寬屏空間，全鏈路一覽無餘無需滾動尋找。 大屏多工、重度依賴上游輸入比對的高階工作流。 ★★★☆☆ (小螢幕需換行適應)
