# 本地化：模块字典与语言包

## 事实源与模块边界

界面文案按业务模块保存在 `web/src/i18n/messages/<module>/<locale>.json`。`core` 承接原 `web/src/i18n.tsx` 的中英文字典和已有 key；Canvas 的界面文案放在 `canvas`，服务端运行状态及系统日志放在 `canvas-runtime`。新增功能优先在对应模块维护，含义一致的通用操作继续使用已有公共 key。

`web/src/i18n/catalog.ts` 汇总内置 `zh`、`en` 字典，保留精确的翻译 key 类型。`web/src/i18n.tsx` 只维护 Provider、语言选择、语言包加载、参数替换和回退；组件仍通过同一个 `useT()` / `useI18n()` 读取当前语言，不建立模块独立的语言状态。

Canvas 两个模块提供全部 14 种语言：`zh`、`en`、`de`、`es`、`fr`、`it`、`ja`、`ko`、`pt`、`ru`、`tr`、`zh-TW`、`zh-Hant`、`zh-HK`。额外语言模块文件是这些模块的翻译源；`locales/*.json` 仍是对外发布的扁平下载包，保留现有服务器安装与下载接口。语言模块源码不要求把所有语言一起打进首屏。

## 新增和修改文案

1. 在模块的 `zh.json`、`en.json` 中添加有语义且带模块归属的 key，例如 `canvas.deleteConfirm`；历史 key 无需为了拆文件而改名。
2. 动态值使用 `{name}`、`{count}` 等命名占位符，通过 `t(key, vars)` 传入，避免拼接完整句子。所有语言必须保留同一组占位符。
3. 在该模块的额外语言源文件中补齐翻译。维护完整语言模块时，翻译 key 必须与该模块中文一致，不得以复制英文或简体中文冒充已经完成的翻译。
4. 运行 `npm run i18n:sync` 更新下载包，再运行相关字典、语言包、死 key 和 Canvas 单测。中英文字典及下载包保持同一合并顺序。

只翻译 UI：按钮、字段标签、状态、操作提示、角色与参数的操作说明使用显式 key，元数据里的角色、状态、端口等通过固定 key 映射取值，避免运行时拼接翻译 key。模板选择名称、Pstack 名称与分类可以作为界面信息本地化。

具体内容统一使用英文源，包括 Pstack 的官方说明与规约正文、执行 Prompt、默认 instruction、模板实际任务和示例任务正文。这些内容不进入语言字典，不随界面语言改写。用户保存的名称、指令、AI 回复、工具输出及导入数据按原文保留。

## 服务端运行消息

服务端系统状态和日志在协议中附带 `CanvasMessage`：`{ key, vars? }`。节点通过 `currentActionMessage`、`errorMessage` 携带状态和错误的消息元数据，日志通过 `CanvasNodeLogEntry.message` 携带，`canvas_error` 通过 `messageI18n` 携带。

原有 `currentAction`、`error`、日志 `text` 和错误 `message` 继续作为兼容文本。服务端保存和前端导入共用消息形状校验，限制 key 为字符串、参数为字符串或有限数字。浏览器用自己的当前语言翻译已知消息 key，未知 key、损坏的历史元数据或旧数据回退原文；同一运行可以被使用不同语言的浏览器同时查看。插值只处理原模板一次，用户值里的 `{count}`、`$&` 等内容保持字面原文。AI 回复和用户输入不附加系统消息元数据。

状态合并时，新的原文必须同时替换对应元数据；原文更新而消息元数据缺省代表清除旧元数据，不能继续显示上一次运行的系统提示。消息元数据与其他运行字段一样参与持久化合并，不能被过期的拓扑保存覆盖。

## 工具与验证

`scripts/lib/i18n-catalog.mjs` 是 Node 工具读取字典的统一入口，负责模块发现、确定合并顺序、重复 key 和各语言 key / 占位符校验。翻译工具不再从 React 文件的位置或正则提取推断当前字典。

- `npm run i18n:sync`：读取模块字典，补齐、清理并重排 `locales/*.json`；模块已有的额外语言翻译覆盖下载包的同 key。传统语言包的其他文案继续保留。
- `npm run i18n:diff -- --base <ref>`：与 Git 基准比较翻译变化，支持基准仍为单个 `i18n.tsx` 的旧布局。
- `npm run i18n:check`：检查下载包与当前字典的同步情况。
- `node scripts/zh-tw-locale/build-all.mjs`：通过统一同步入口更新繁体语言包，模块明确提供的繁体译文优先。

对应守卫包括模块字典一致性、下载包 key 与占位符、同步器回归、死 key、Canvas 前端契约及后端消息生命周期。新增模块还须在浏览器字典入口登记，确保工具读取到的模块与实际运行时一致。
