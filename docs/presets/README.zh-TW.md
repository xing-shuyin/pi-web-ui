# 編碼工作流實驗預設

[claude-code-inspired.json](./claude-code-inspired.json) 是可匯入的 pi-web-ui 預設，借鑑調查、根因修復、持續執行和驗證閉環等編碼實踐。它不是 Anthropic 官方預設，也未複製或核對某個版本的 Claude Code 系統提示詞，不保證提高所有模型或任務的表現。

## 匯入與恢復

1. 在設定的預設管理中，先儲存並匯出當前配置，作為恢復副本。
2. 匯入本目錄的 JSON，檢查匯入預覽，再應用“Claude Code 風格編碼（實驗）”。
3. 在提示詞設定中檢查展開結果；主會話的後續回合使用新模板。需要恢復時應用原先儲存的預設。

該檔案僅包含 `promptTemplate`、`promptOverrides`、`promptDisabled` 三個欄位。模板保留全部 11 個動態來源，並在末尾追加英文編碼工作流，以便工具說明、專案規範、技能及工作目錄繼續由執行環境生成。`append` 仍保留自動內容，包括已有的 `APPEND_SYSTEM.md`。

應用後會替換當前組合模板、清空已有逐段覆蓋，並重新啟用所有提示詞段。若依賴自定義 `soul`、`guidelines` 或其他逐段覆蓋，應用後需要自行合併；匯入前請檢視預覽。模型、思考強度、工具、許可權和上下文引數未包含在該預設中。預設應用仍經過宿主的統一設定與工具門控流程。

該主會話模板不會自動覆蓋子代理角色模板。計劃、審查、審批等模式約束仍由宿主執行；此工作流要求尊重這些約束。

## 對照評估

在相同倉庫提交、模型版本、思考強度、工具許可權及任務輸入下，分別使用原配置和實驗預設。每次從獨立的新會話開始，避免先前調查結果影響比較。選擇幾項真實修復和功能任務，記錄：

- 是否定位正確入口、呼叫鏈及權威狀態，是否解決根因。
- 修改是否完整，是否引入無關重構或遺漏呼叫方。
- 是否完成相關檢查，報告的結果是否與實際執行一致。
- 迴歸情況、人工返工量，以及時間和 token 成本。

提示詞效果具有隨機性，單次結果不足以證明整體改善。若差異源自工具輸出丟失、上下文恢復或執行錯誤，應修復對應機制。
