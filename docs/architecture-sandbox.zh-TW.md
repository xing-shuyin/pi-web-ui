# 沙盒工作區

沙盒是服務端管理的專案副本。檔案工具只能訪問受管目錄；沒有作業系統隔離後端時，不允許通過宿主 shell、直譯器、任意程式碼或未知工具執行副作用。沙盒不應被宣傳為允許任意程式執行的容器。各執行引擎必須在執行前具備同等拒絕能力，不具備時拒絕在沙盒啟動任務。

## 身份與准入

沙盒身份繫結執行會話並繼承到子代理。切換 cwd、派生執行者、恢復會話均不能解除邊界；沙盒父執行者不得通過指定外部 cwd 或 worktree 派生突破邊界。註冊記錄失效、受管目錄身份未知、生命週期操作正在進行時拒絕執行，不能退化成普通工作區。

檔案路徑檢查同時覆蓋詞法路徑與真實路徑，拒絕軟連結、junction、硬連結及特殊檔案。宿主工具按明確能力放行，未知能力預設拒絕；不得用擴充 shell 正則的方式承諾任意程式碼隔離。外掛、MCP、直譯器、終端輸入和工具編排入口同樣屬於執行邊界。SDK 搜尋工具可能繼承宿主命令配置，`grep/find` 在提供專用安全實現前同樣拒絕。

沙盒執行時不載入磁碟擴充套件、SDK 內建擴充套件、外掛或 MCP 工具；最終 SDK 執行前檢查還要驗證工具定義和 execute 的原始引用，防止同名替換獲得信任。當前最終工具白名單也不放行沙盒內模型派發子代理；宿主子代理入口仍驗證父級身份和 cwd，防止其他路徑繞過。沙盒內管理工具僅可列出自身後設資料、將自身轉為永久保留；匯入、源專案對比、匯出、重置、寫回、銷燬由沙盒外的控制面發起。使用者在 UI 上進行預覽和管理不受此模型工具限制。

## 基線與寫回

匯入儲存獨立基線。差異表示沙盒相對基線的修改；寫回使用基線、當前源專案和當前沙盒三方比較，只提交沙盒改動，保留源專案獨立產生的檔案與修改。雙方同時修改同一目標時拒絕並報告衝突。

寫回繫結預覽版本：使用者預覽之後任一參與內容發生變化，必須重新預覽。執行時重新驗證真實目標路徑，拒絕沿目標軟連結、junction 或其他不安全目標寫入。寫入先在源專案同一檔案系統暫存並保留恢復對映，失敗回滾前核對目標仍為本次寫入內容；發現源端併發修改則保留當前內容與備份並報告恢復路徑。目錄刪除按深度逆序執行，失敗不能返回成功。舊沙盒缺少可信基線時允許檢視和匯出，但拒絕直接寫回。

## 生命週期與持久化

同一 data-dir 內各會話共享倉庫，註冊變更序列提交併原子持久化。持久化失敗必須向呼叫方報告，不能先發布成功執行態。

重置、寫回、銷燬先凍結新執行，協調全部持有該沙盒的執行時、子代理和相關終端，等待在途操作退出後再修改檔案。失敗保留可識別且受保護的狀態，供重試。銷燬完成前不得撤銷沙盒身份；停止範圍按沙盒確定，不影響其他專案或使用者終端。

重置準備完整的新副本後提交，避免邊刪除邊複製導致新舊檔案混合。銷燬先將內容重新命名到可恢復的暫存位置，再提交登錄檔刪除；提交失敗還原目錄，清理失敗報告恢復路徑。檔案佔用或清理失敗不能僅警告後報告成功。複製逐檔案驗證副本與源快照的內容、許可權一致，掃描限制 15,000 個條目、64 MB 單檔案和 512 MB 累計檔案位元組，避免無界佔用。

## 驗證重點

迴歸必須覆蓋：源專案獨立新增和修改、雙方衝突、刪除與型別變化、預覽過期、目標軟連結/junction、併發建立、持久化失敗、註冊身份失效、執行中重置與銷燬、父子許可權繼承、終端和未知工具旁路，以及不支援隔離的引擎拒絕啟動。

核心實現位於 `server/sandbox-service.ts`、`server/sandbox-tool.ts` 和各引擎會話入口。協議位於 `server/protocol.ts`，前端入口為 `web/src/components/SandboxModal.tsx`。
