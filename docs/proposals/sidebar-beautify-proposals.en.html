Option 1: drop the folder icon entirely (strongly recommended)

Restores exactly the outline-style purity of your first screenshot: nothing but the collapse chevron v, with the project name pi-web-ui right behind it. No chunky yellow-and-black folder glyph cutting into the view — the text breathes, it reads modern, closer to Linear, Notion or an outliner.

    🔍 Why does removing the folder icon look better?

    ✨
    Kills the skeuomorphic weight: on a dark theme the traditional folder icon looks like a Windows 98 leftover — it burns 16px of width and makes the layout clumsy;
    ✨
    Sharpens the chevron's wayfinding: with the folder gone, the chevron (expanded points down ▼, collapsed points right ▶) becomes the only focal point, so the hierarchy reads cleaner and purer;
    ✨
    A 100% match for the mock you started from: your first mock felt the most comfortable precisely because the project header carried no stray icons at all!
