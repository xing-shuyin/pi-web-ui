方案 1：彻底去掉文件夹图标（极力推荐）

完全还原你第一张截图中那种大纲式纯净感： 只有折叠箭头 v，紧接着就是项目名 pi-web-ui！ 没有任何黄黄黑黑的厚重文件夹图标打扰视野，文字更大气、更现代，类似 Linear、Notion、大纲笔记。

    🔍 为什么去掉文件夹图标更好看？

    ✨
    消除拟物化笨重感： 在暗色主题下，传统的文件夹图标像 Windows 98 时代的残留，不仅占了 16px 宽度，而且让排版变笨拙；
    ✨
    强化 Chevron 箭头的导向性： 去掉文件夹后，折叠箭头（展开向下 ▼，收起向右 ▶）变成了唯一的视觉焦点，层级认知更加纯粹清晰；
    ✨
    100% 吻合你最初发的设计图： 你发的第一张图之所以看起来最舒服，正是因为项目头没有加任何杂乱的图标！
