✨ 智能半折叠（Partial Collapse）交互演示

你提出的“折叠只隐藏没运行的”是极为高明的设计：既满足了用户将大量历史记录折叠收纳、保持侧边栏清爽的诉求，又彻底消除了后台 Agent 被掩盖的风险！

模拟操作：
状态 A：展开状态（Full Expand） 项目展开时，运行中的 2 个任务置顶显示，历史对话在下方列出。
状态 B：折叠状态（Partial Fold · 核心新逻辑） 用户点击折叠项目：静态历史对话全部收起；但正在运行的任务依然悬挂在项目标题下方，进度/转圈实时可见，绝不漏掉任何执行状态！下方还会出现「+ 展开 3 条历史」入口。
状态 C：任务完成后自然归位 当后台运行的任务跑完后，如果当前项目处于折叠态，该任务将自然融入折叠的历史中，项目完全闭合为单行。没有任何生硬跳变！
