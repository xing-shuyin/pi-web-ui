💡 提示詞模板（Prompt Template）UI 互動升級

針對當前提示詞模板彈窗存在的“垂直堆疊臃腫”、“Emoji 選擇不便”、“命令與變數指引割裂”、“編輯器缺乏引數高亮與輔助”等痛點，提供 3 版不同維度的現代化改進方案。頁面支援真實互動、變數點選注入、雙欄即時預覽與全套主題變數測試。

✨ 圖示/標題行一體化 ⚡ 快捷命令與說明 2 列柵格 🧩 動態引數 `{{input}}` 快捷插入 🎨 沉浸式 Markdown 編輯器 ⌨️ 快捷鍵清晰對映

🚀 方案一：現代流線型 · 緊湊一體化 (Modern Integrated Flow)

在保持彈窗輕便度的前提下，將垂直空間利用率提升 40% 以上，圖示選擇更友好，並引入變數藥丸膠囊。

✨ 方案一核心改進點

  • 圖示與標題合二為一：頭部由原先「圖示一行、標題一行」的呆板排版，升級為現代 App 標配的複合頭欄。點選左側圖示可直接彈窗點選常用 Emoji，無需手動複製貼上。
  • 快捷命令帶膠囊字首 /：內建前置斜槓視覺錨點，自動合併命令與說明為雙列，縱向壓縮高度約 110px，讓首屏焦點完整停留在提示詞上。
  • 動態佔位符一鍵插入工具條：在輸入框頂欄直觀列出 {{input}} / {{clipboard}} 膠囊，點選游標位置直接注入，避免使用者記不住語法。
  • 三級操作層次分明：次要「儲存修改」為柔和色；中頻「填入輸入框」採用 Accent-Soft 主色背景；核心「直接傳送」為主實色按鈕並標註鍵盤快捷鍵。

⚡ 方案二：雙欄工作臺 · 專業生產力 (Studio Split Pro)

專為複雜工程提示詞、系統指令配置與重度創作者打造。左側管控引數與測試用例，右側沉浸式編寫與變數即時預覽。

✨ 方案二核心優勢

  • 沉浸式長文本編輯：寬度擴充套件至 940px，提示詞區域擁有接近全屏的編輯體驗，不再擁擠在 300px 的矮小區域內。
  • 首創變數即時偵錯程式 (Variable Simulator)：當輸入 {{input}} 時，左側自動解析出引數輸入框，右側一鍵切換「渲染預覽」，所見即所得。
  • 專業工程感：非常適合需要編寫結構化 System Prompt、複雜 CI 釋出工作流、格式約束模板的高階使用者與工程師。

🎯 方案三：極簡命令流 · Raycast 風格 (Command Palette Style)

極致鍵盤驅動，去除非必要邊框與卡片層級，突出 Slash Command 命令快捷感與極簡極客體驗。

✨ 方案三核心特點

  • 無縫 Command 融合：將快捷指令作為視覺一級焦點，輸入 /pb 直接作為標題前導標籤，符合工程師直覺。
  • 去除視覺噪音：去掉沉重的 Label/Input 外框，用一體化的大字號與輕柔虛線/下邊框，更輕快、更現代化。
  • 狀態列式底部：仿照 Raycast / VSCode 的快捷鍵狀態列，讓高頻操作盡在指尖。
