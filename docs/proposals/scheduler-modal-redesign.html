UI / UX 提案 · 任务调度模块

定时任务创建/编辑弹窗重构方案

针对现有定时任务弹窗「宽度仅 460px、单列单行罗列、Prompt 区域局促、调度无自然语义翻译与触发预览」的问题，提供三套经过深思熟虑的高保真重构方案。

原版痛点 1 · 视觉逼仄
460px 宽度单列堆叠
沿用基础弹窗尺寸，10 项字段垂直平铺，像一张毫无呼吸感的信息表格，小家子气。
原版痛点 2 · Prompt 残疾
核心指令区仅 4 行高度
定时任务的核心是给智能体的具体指令（Prompt），狭小输入框极难书写多步骤巡检脚本。
原版痛点 3 · 调度无心智反馈
纯生硬 Cron / 预设
选了或写了 Cron 后，缺少中文自然语言解读与「接下来执行时间」预演，用户心里没底。
改进抓手 · 根本解决
结构分区 + 宽屏 + 调度智能翻译
分卡片/分栏布局，大 Prompt 空间 + 预设场景模板，可视化 Cron 预演，高级项收纳。
💡 点击方案内的预设胶囊或模板，可实时交互体验！

方案 A：现代分块卡片式 (Modern Sectioned Cards) 强烈推荐 · 大气稳健

宽度拓展至 720px。采用现代 Cloud / DevOps 面板标准规范，划分为 「任务目标与指令」、「调度周期与执行预演」、「运行时与模型环境」 三大逻辑卡片，主次清晰，Prompt 拥有极大自由度。

方案 B：双栏工程驾驶台 (Split Workbench Studio) 重度开发者 · 驾驶舱视野

宽度拓展至 880px。采用类似现代 IDE 与流水线编排器（如 GitHub Actions / Temporal）的 左工作区（60%）+ 右检视区（40%） 结构。左侧专注于任务指令编写与目标，右侧拥有完整的触发流水线时间轴预演。

方案 C：分步聚焦向导式 (Step Flow Wizard) 低心智负担 · 渐进聚焦

宽度 650px。将原本臃肿的表单拆解为 ① 任务与调度、② 指令编写、③ 运行环境 三个平滑步骤。每一步仅关注核心输入项，清晰不压抑，适合绝大多数常规任务创建。

4
高级项优雅收纳，开关动效丝滑
模型、思考等级、停机补偿采用并排网格与 iOS 风格 Switch，取代突兀的原生单选框。
