定時任務建立/編輯彈窗重構方案

針對現有定時任務彈窗「寬度僅 460px、單列單行羅列、Prompt 區域侷促、排程無自然語義翻譯與觸發預覽」的問題，提供三套經過深思熟慮的高保真重構方案。

原版痛點 1 · 視覺逼仄
460px 寬度單列堆疊
沿用基礎彈窗尺寸，10 項欄位垂直平鋪，像一張毫無呼吸感的資訊表格，小家子氣。
原版痛點 2 · Prompt 殘疾
核心指令區僅 4 行高度
定時任務的核心是給智慧體的具體指令（Prompt），狹小輸入框極難書寫多步驟巡檢指令碼。
原版痛點 3 · 排程無心智反饋
純生硬 Cron / 預設
選了或寫了 Cron 後，缺少中文自然語言解讀與「接下來執行時間」預演，使用者心裡沒底。
改進抓手 · 根本解決
結構分割槽 + 寬屏 + 排程智慧翻譯
分卡片/分欄佈局，大 Prompt 空間 + 預設場景模板，視覺化 Cron 預演，高階項收納。
💡 點選方案內的預設膠囊或模板，可即時互動體驗！

方案 A：現代分塊卡片式 (Modern Sectioned Cards) 強烈推薦 · 大氣穩健

寬度拓展至 720px。採用現代 Cloud / DevOps 面板標準規範，劃分為 「任務目標與指令」、「排程週期與執行預演」、「執行時與模型環境」 三大邏輯卡片，主次清晰，Prompt 擁有極大自由度。

方案 B：雙欄工程駕駛臺 (Split Workbench Studio) 重度開發者 · 駕駛艙視野

寬度拓展至 880px。採用類似現代 IDE 與流水線編排器（如 GitHub Actions / Temporal）的 左工作區（60%）+ 右檢視區（40%） 結構。左側專注於任務指令編寫與目標，右側擁有完整的觸發流水線時間軸預演。

方案 C：分步聚焦嚮導式 (Step Flow Wizard) 低心智負擔 · 漸進聚焦

寬度 650px。將原本臃腫的表單拆解為 ① 任務與排程、② 指令編寫、③ 執行環境 三個平滑步驟。每一步僅關注核心輸入項，清晰不壓抑，適合絕大多數常規任務建立。
