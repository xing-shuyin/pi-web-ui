✨ 智慧半摺疊（Partial Collapse）互動演示

你提出的“摺疊只隱藏沒執行的”是極為高明的設計：既滿足了使用者將大量歷史記錄摺疊收納、保持側邊欄清爽的訴求，又徹底消除了後臺 Agent 被掩蓋的風險！

模擬操作：
狀態 A：展開狀態（Full Expand） 專案展開時，執行中的 2 個任務置頂顯示，歷史對話在下方列出。
狀態 B：摺疊狀態（Partial Fold · 核心新邏輯） 使用者點選摺疊專案：靜態歷史對話全部收起；但正在執行的任務依然懸掛在專案標題下方，進度/轉圈即時可見，絕不漏掉任何執行狀態！下方還會出現「+ 展開 3 條歷史」入口。
狀態 C：任務完成後自然歸位 當後臺執行的任務跑完後，如果當前專案處於摺疊態，該任務將自然融入摺疊的歷史中，專案完全閉合為單行。沒有任何生硬跳變！
