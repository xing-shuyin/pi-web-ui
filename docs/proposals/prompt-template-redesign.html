💡 提示词模板（Prompt Template）UI 交互升级

针对当前提示词模板弹窗存在的“垂直堆叠臃肿”、“Emoji 选择不便”、“命令与变量指引割裂”、“编辑器缺乏参数高亮与辅助”等痛点，提供 3 版不同维度的现代化改进方案。页面支持真实交互、变量点击注入、双栏实时预览与全套主题变量测试。

✨ 图标/标题行一体化 ⚡ 快捷命令与说明 2 列栅格 🧩 动态参数 `{{input}}` 快捷插入 🎨 沉浸式 Markdown 编辑器 ⌨️ 快捷键清晰映射

在保持弹窗轻便度的前提下，将垂直空间利用率提升 40% 以上，图标选择更友好，并引入变量药丸胶囊。

✨ 方案一核心改进点

  • 图标与标题合二为一：头部由原先「图标一行、标题一行」的呆板排版，升级为现代 App 标配的复合头栏。点击左侧图标可直接弹窗点选常用 Emoji，无需手动复制粘贴。
  • 快捷命令带胶囊前缀 /：内置前置斜杠视觉锚点，自动合并命令与说明为双列，纵向压缩高度约 110px，让首屏焦点完整停留在提示词上。
  • 动态占位符一键插入工具条：在输入框顶栏直观列出 {{input}} / {{clipboard}} 胶囊，点击光标位置直接注入，避免用户记不住语法。
  • 三级操作层次分明：次要「保存修改」为柔和色；中频「填入输入框」采用 Accent-Soft 主色背景；核心「直接发送」为主实色按钮并标注键盘快捷键。

✨ 方案二核心优势

  • 沉浸式长文本编辑：宽度扩展至 940px，提示词区域拥有接近全屏的编辑体验，不再拥挤在 300px 的矮小区域内。
  • 首创变量实时调试器 (Variable Simulator)：当输入 {{input}} 时，左侧自动解析出参数输入框，右侧一键切换「渲染预览」，所见即所得。
  • 专业工程感：非常适合需要编写结构化 System Prompt、复杂 CI 发布工作流、格式约束模板的高级用户与工程师。

  • 无缝 Command 融合：将快捷指令作为视觉一级焦点，输入 /pb 直接作为标题前导标签，符合工程师直觉。
