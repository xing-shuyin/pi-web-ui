方式 1：无竖条·柔光全药丸高亮（彻底跳出竖条陷阱）

为什么刚才我们会反复被“竖条插在文字上”、“跑出去了”困扰？因为传统的“左侧 3px 白色竖条”是一个有结构性缺陷的旧设计：它强迫左侧必须留出额外的空白塞竖条，极易被全局 padding 冲刷。

更好的现代解法：像 Linear、Raycast、Slack、macOS 原生一样，彻底扔掉生硬的竖条！采用整行微圆角半透明底色（Soft Pill Highlight）！

    💡 架构决策深度分析

    🎯
    为什么“去竖条化”是所有现代专业工具的必然趋势？
    Cursor、VS Code 现代主题、Linear 都在近两年彻底移除了左侧生硬的高亮细条，改用全行微透明背景。这样不但没有文字对齐风险，而且在移动端、触摸屏和窄屏幕上表现极其坚固稳定。
    ⚡
    手风琴（方式 2）为什么适合 20+ 个项目？
    如果一个用户有 25 个项目，按普通折叠展开 3 个就会把列表撑到两千像素高。如果采用“自动收起其他，仅保留当前项目 + 正在运行的后台任务”，整个侧栏的高度永远处于极度克制的一屏内。
