💡 Prompt Template UI Interaction Upgrade

The current prompt-template modal suffers from bloated vertical stacking, awkward Emoji selection, split command/variable guidance, and an editor with no parameter highlighting or assistance. This page offers 3 modernization options along different axes. Everything here is live: real interactions, click-to-inject variables, side-by-side live preview, and a full test of the theme variables.

✨ Icon/title merged into one row ⚡ 2-column grid for command and description 🧩 One-click insert of dynamic `{{input}}` params 🎨 Immersive Markdown editor ⌨️ Clearly mapped keyboard shortcuts

Keeps the modal light while lifting vertical space efficiency by 40%+, makes icon picking friendlier, and introduces variable pills.

✨ What Option 1 improves

  • Icon and title merged into one: the header moves from the old rigid “icon on one row, title on the next” layout to the composite header every modern app uses. Clicking the icon on the left opens a picker of common Emoji — no manual copy-paste.
  • Slash command with a pill-shaped / prefix: a built-in leading-slash visual anchor merges command and description into two columns and saves about 110px of height, so the first screen stays focused on the prompt.
  • One-click insert bar for dynamic placeholders: the bar above the input plainly lists {{input}} / {{clipboard}} pills; a click injects them at the cursor so nobody has to memorize the syntax.
  • Three distinct action tiers: the secondary “Save changes” stays soft; the mid-frequency “Fill composer” uses an Accent-Soft background; the primary “Send now” is a solid accent button labelled with its shortcut.

✨ What makes Option 2 strong

  • Immersive long-form editing: the modal widens to 940px, so the prompt area feels almost full-screen instead of being crammed into a 300px-tall box.
  • First-of-its-kind live variable simulator: type {{input}} and the left pane automatically parses out a parameter field, while the right pane flips to “Rendered preview” in one click — WYSIWYG.
  • Professional engineering feel: ideal for power users and engineers writing structured system prompts, complex CI release workflows or format-constrained templates.

✨ What sets Option 3 apart

  • Seamless command integration: the slash command is a first-class visual focus — typing /pb turns it into the leading tag of the title, which matches how engineers think.
  • Visual noise removed: heavy label/input boxes are gone, replaced by integrated large type and soft dashed or underline borders — lighter and more modern.
  • Status-bar footer: modelled on the Raycast / VSCode shortcut status bar, keeping high-frequency actions at your fingertips.
