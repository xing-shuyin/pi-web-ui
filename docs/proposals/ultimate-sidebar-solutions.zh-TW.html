方式 1：無豎條·柔光全藥丸高亮（徹底跳出豎條陷阱）

為什麼剛才我們會反覆被“豎條插在文字上”、“跑出去了”困擾？因為傳統的“左側 3px 白色豎條”是一個有結構性缺陷的舊設計：它強迫左側必須留出額外的空白塞豎條，極易被全域性 padding 沖刷。

更好的現代解法：像 Linear、Raycast、Slack、macOS 原生一樣，徹底扔掉生硬的豎條！採用整行微圓角半透明底色（Soft Pill Highlight）！

    💡 架構決策深度分析

    🎯
    為什麼“去豎條化”是所有現代專業工具的必然趨勢？
    Cursor、VS Code 現代主題、Linear 都在近兩年徹底移除了左側生硬的高亮細條，改用全行微透明背景。這樣不但沒有文字對齊風險，而且在移動端、觸控式螢幕和窄螢幕上表現極其堅固穩定。
    ⚡
    手風琴（方式 2）為什麼適合 20+ 個專案？
    如果一個使用者有 25 個專案，按普通摺疊展開 3 個就會把列表撐到兩千畫素高。如果採用“自動收起其他，僅保留當前專案 + 正在執行的後臺任務”，整個側欄的高度永遠處於極度剋制的一屏內。
