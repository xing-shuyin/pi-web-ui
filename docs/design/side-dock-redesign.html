00 / 诊断

割裂和横向滚动条，是三个独立问题叠出来的

左边是现在的样子：一个 border + 阴影 + 半透明模糊的胶囊贴在面板边上，而面板自己是另一张卡片， 于是「两层框」互相切割。同时胶囊内部 overflow-y: auto 让 overflow-x 被计算成 auto，而 tooltip 伪元素是往右伸出的，于是横向滚动条被撑了出来。

现状复刻（左侧收窄）
1
两层卡片语言打架

dock 有 border + 阴影 + backdrop-filter，面板又是另一张带 border 的卡片，中间还留了透明缝 —— 眼睛会读成「两个不相干的浮层」。

2
竖向列表里冒出横向滚动条

只声明了 overflow-y: auto，另一轴会从 visible 计算成 auto；而 [data-tip]::after 用 left: calc(100% + 8px) 往右伸出，撑大了可滚动区域。

/* 现状 */ .side-dock-seg { overflow-y: auto; } ← 横向也被 auto .side-dock [data-tip]::after { left: calc(100% + 8px); } ← 撑宽 /* 修法 */ .side-dock-seg { overflow-y: auto; overflow-x: clip; } // tooltip 改成单例 fixed 浮层，不进滚动容器
3
尺寸语言没统一

同一列里混着 30px 圆形 border-radius: 50% 的 bar item、22px 的折叠键、18px 的引擎徽标；和顶栏 28px 圆角 8px 的按钮、状态栏 11px 的字号不构成一套。

4
整列只有 70vh 高

.side-dock-float { height: 70vh; top: 50% } 决定它天然不可能「贯通」， 上下都是空气，视觉重量和左右面板不在同一根线上。

方案 A

无形之栏：贯通整列，完全透明

推荐

不画卡片、不画外框、不画阴影 —— 图标直接坐在和顶栏、面板同一块表面上，从顶栏下沿贯通到状态栏。 位置感只靠「1px 发丝线」+「激活态左侧 3px 竖条」建立。hover 时只长出一块药丸底， 并向右滑出文字标签，解决纯图标不可读的问题。

怎么做到「贯通」

  • 列宽固定 --rail-w: 56px，高度吃 flex，不再有 70vh / translateY。
  • 底色与顶栏、面板同为 --bg-elev：三者连成一片 L 形表面，不再是贴上去的卡片。
  • 与面板之间只留 1px --border-soft 发丝线；不画外框、不画阴影。
  • 底部图标用 margin-top: auto 顶到底，跟状态栏留 9px 呼吸。

取舍

＋ 改动最小：只动 .side-dock* 的 30 行 CSS + SideDock 根节点。

＋ 最接近 Linear / Arc 的「无容器」观感，和任意主题都好配。

− 纯图标可读性依赖 hover 标签，触屏上要退回长按提示。

适配细节

  • 图标 19px / 命中区 36px / 圆角 11px / 间距 3px，与顶栏 28px 按钮同族。
  • 扫描插件槽位：align=start/center/end 三槽保留，视觉上只表现为「空隙 + 1px 细线」。
  • 标签用绝对定位，但 rail 不能设 overflow，否则又被裁。
方案 A · 手机版

同一列，收窄到 46px

手机上没有第二个面板——左右面板都变成抽屉，所以这条竖列是唯一常驻的导航。它不能消失，也不能吃掉太多宽度： 列宽从 56 收到 46，命中区从 36 拉到 38（拇指能稳稳点中），悬停标签改成关掉（触屏没有 hover）， 其余（贯通、发丝线、激活竖条）与桌面完全一致。右侧列只在真有条目时出现，空的时候不占位。

手机上的规则

  • 列宽 46px、按钮 38px、间距 4px（触控命中区下限）。
  • 不弹悬停标签（触屏无 hover）；保留 title 供长按提示。
  • 左右面板都是抽屉，列不跟着抽屉走，始终贯通全高。
  • 右列没有条目时整列 display:none，不白占 46px。

为什么不用底部 tab bar

底部已经有输入框 + 状态栏，再加一条 tab 会变成三层。竖列与桌面同一套 DOM， 只用媒体查询换尺寸，改动面最小；且手机横屏时列自动变回“侧栏”的直觉位置。

方案 B

一体双栏：dock 和面板住进同一张卡片

割裂的根源是「两个浮层」。这个方案反过来：dock + 面板合成一个容器，只有一条外边框、一个圆角； dock 用比面板深一档的底色区分层级，中间一条 1px 内线。中间会话区不再是「被两块卡片夹住」， 而是反过来浮在画布上 —— 也就是 Figma / Linear 桌面版的骨架。
