終端下沉為底部抽屜，Git 升級為右側檢閱抽屜

現狀：終端與 Git 都是全頁 .view-pane 切頁，看一行編譯錯誤就把對話頂掉。 本方案把兩類工具按真實使用姿勢重新歸位：終端 = 執行態（邊聊邊跑，底部可拖抽屜）； Git = 檢閱態（邊看 diff 邊讓 agent 改，右側非模態寬抽屜）。手機端兩者統一退化為全屏 sheet。

終端不再打斷對話 diff 有寬度、上下文不丟 手機端不做上下分屏 xterm 例項常駐不重建 不是兩個彈窗疊在聊天上

手機端

不做上下分屏；兩個工具都退化為全屏 sheet，靠頂部把手下拉關閉

為什麼手機不做分屏

  • 螢幕高度 ~740px，上下分屏後對話區只剩兩三個氣泡，比全頁切換更差。
  • 軟鍵盤彈出會再吃掉 40%高度，xterm 和輸入框搶空間，fit() 會瘋狂抖動。
  • 手機上終端的高頻場景是「看一眼命令是否跑完」，全屏 sheet + 下拉關閉的心智成本最低。

手機端的三個新增

  • sheet 把手：頂部 34×4 的 grabber + 下拉手勢關閉，替代全頁左上角返回。
  • Git 變成全屏 sheet：頂部 segmented 切 Changes / History，檔案列表 → diff 二級下鑽。
  • tab 變橫向 chips：多終端在窄屏用可滑動 chips，不再擠成一排小方塊。

規格

尺寸、動效、語義色都從這裡取，落地時不再臨時拍數值

佈局與尺寸

項桌面 ≥1100px平板 768–1100手機 <768
終端底部抽屜，180 / 318 / 70vh同左，預設 280全屏 sheet，64vh → 100dvh
Git右側抽屜，480 / 672 / vw−380640，與右欄二選一全屏 sheet
與聊天關係終端擠壓，Git 擠壓（不遮擋）同左兩者都覆蓋
摺疊態39px 條，tab 與入口仍在39px下拉即關閉

動效與手感

  • 展開/收起 height 220ms cubic-bezier(.22,1,.36,1)；拖拽中加 .dragging 關掉 transition，鬆手再開。
  • Git 抽屜用 width + opacity 擠壓工作區，而不是 translate 滑入——滑入會蓋住底部終端，兩者同時開啟時會打架。
  • 把手熱區 9px，視覺只有 36×3；hover 變寬到 52 並染 accent——小尺寸但不難點。
  • 執行中用 2.2s 脈衝點，不用無限旋轉 spinner（終端裡已有輸出，兩個動效會打架）。
  • 全程只動 transform/opacity/height，不碰 top/left/width（Git 抽屜寬度除外，拖拽時它就是主任務）。

視覺規則

  • 層次靠背景差，不靠描邊：--bg → --bg-elev → --bg-elev2 三檔 + 1px --border-soft。
  • accent 只給三件事：當前 tab 下劃線、主按鈕、焦點環。其餘全中性。
  • 語義色只標狀態：M 琥珀 / A 綠 / D 紅 / U 藍，都用 15×15 圓角方塊 + mono 單字母，不寫全詞。
  • 路徑與數字一律 mono且 tabular-nums，diff 行號右對齊不跳動。
  • 圓角三檔：外框 14 · 卡/抽屜 10 · chip/kbd 5–7。不出現 4px 以下圓角，避免“老後臺”感。

資訊架構重排（這才是“變好看”的關鍵）

  • 終端：舊版左側 aside 同時塞了“命令列表 + tab 列表”，兩層導航並列。新版把命令列表降級為按需浮層（Commands 按鈕 / Ctrl+K），抽屜頭只留 tab 與動作。
  • Git：舊版頂部 4 行按鈕堆（分支、stash、branch、amend、blame…）。新版只留一行（分支 + fetch/pull/push + 關閉），其餘收進 ⋯ 選單。
  • 提交動作常駐底部：commit 是高頻終點，不該在滾動區裡隨內容漂移。
  • Changes / History / Stash 變成 segmented，取代三個同等權重的按鈕。
  • AI Bash 仍是摺疊組，但用「組頭 + 計數」表達，不再和使用者 tab 視覺同級。

04

落地要點

按專案既有約束寫，避免返工與守衛失敗

必須守住的

  • xterm 例項常駐：摺疊只 display:none，不解除安裝；否則 2MB 緩衝全量重放會閃屏。
  • 拖拽期間節流 fit：ResizeObserver 回撥裡判斷 resizing，鬆手後補一次測量。
  • DeferredMount 語義：從 view==="terminal" 改成“抽屜曾經開啟過”，首次開啟才掛載。
  • 層級走 useOverlayZIndex()，不寫死 z-index（overlay-stack 守衛）。
  • 底部安全區：env(safe-area-inset-bottom) 計入抽屜高度，別讓最後一行被 Home 條蓋住。
  • 入口保留：TopBar 的 tb-tab、左側 dock、uiSlots 插槽全部保留，只是行為從“切頁”變“開抽屜”。

容易踩的坑

  • 手機手勢打架：已有 useSwipeDrawer 左右滑開側欄；底部上滑必須限定在 grabber 區域，別搶全屏手勢。
  • composer 被頂掉：抽屜展開後若把輸入框擠出可視區，messages-behind-composer 守衛會掛；終端高度上限設 70vh 而不是 90vh。
  • Git 抽屜與右欄衝突：RightPanel 佔右側。規則定為「Git 開啟時右欄自動摺疊，關閉後恢復」——比兩者並列更省寬度。
  • diff 全屏按鈕：SCMPanel 內已有全屏 diff，在抽屜裡保留為“拉滿”逃生艙，避免小屏讀 diff 痛苦。
  • 持久化：高度/寬度沿用 panelWidthKey 那套 localStorage 寫法，鍵名如 pi-web-ui:term-drawer-h。
  • 減少動效：尊重 prefers-reduced-motion，抽屜直接切不滑。
