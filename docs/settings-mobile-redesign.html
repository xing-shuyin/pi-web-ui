4.1 逐状态说明

  • 默认：行高 56，图标托 28，右值 13px --text-dim，箭头 16px；同一屏最多 1 个强调色（开关开启 / 选中），其余靠层级与留白。
  • 按下：:active → 背景 --fill-press（深色 7% 白 / 浅色 6% 黑）+ 磁贴 scale(.975)，120–160ms；不做涟漪、不做投影变化。
  • 禁用：aria-disabled="true" + 图标 45% 透明 + 主文案转 --text-faint + 保留箭头；必须在副文案写清「为什么禁用、去哪修」。
  • 加载：首次进入用骨架屏（不是转圈），aria-busy="true" + aria-label="正在加载设置"；已有内容时改值只更新局部，绝不整页闪。
  • 空：搜索无结果 → 图标 + 「没有匹配"XXX"的设置」+ 建议关键词 + 「清除搜索」按钮。不写「暂无数据」这种无信息文案。
  • 开关：开＝--accent 轨道 + 圆点右移 20px；关＝--track-off。文案层同时给出 aria-checked，不靠颜色单独表达。
  • 进二级页：220ms translateX(16px)+fade 推入；返回反向。Android 用系统返回键，iOS 建议同时开启边缘滑动返回（实现成本低，见落地清单）。
  • 危险操作：行本身只是入口 → 二级页 → 点动作弹底部面板（标题复述对象 + 后果 + 是否不可撤销），确认按钮实底红、取消在下且更高；不用「确定/取消」并排的系统 Alert，拇指更容易误触。
  • 保存策略：全部即时生效，没有「保存」按钮。顶部 28px 胶囊显示 已保存 / 保存中… / 未保存·重试，失败时同时出现红色横幅（role="alert"）+ 行级标红，点任意一处都可重试。这与现有 useSettingsSync 的回执语义一致。
  • 搜索：常驻首页（不折叠成图标）。匹配范围＝行标题 + 副文案 + 分组名 + 二级页标题 + 关键词别名（沿用 TAB_KEYWORDS 的中英别名）。输入 200ms 防抖，结果行带分组面包屑（「· 常用」），可在结果里直接切开关。

5给 Figma / AI 设计工具的视觉描述

function ToggleRow({ row }: { row: Row }) {
  const on = useSetting(row.key);
  return (
    <Pressable
      role="switch"                       // TalkBack / VoiceOver 播报「开关」
      aria-checked={on}
      accessibilityLabel={row.label + (row.desc ? '，' + row.desc : '')}
      onPress={() => setSetting(row.key, !on)}
      style={({ pressed }) => [styles.row, pressed && { backgroundColor: c.fillPress }]}
    >
      <RowIcon icon={row.icon} tone={row.tone} />
      <View style={{ flex: 1, minWidth: 0 }}>
        <Text numberOfLines={1} style={styles.label}>{row.label}</Text>
        {row.desc ? <Text numberOfLines={2} style={styles.desc}>{row.desc}</Text> : null}
      </View>
      <Switch value={on} pointerEvents="none" accessible={false} />
    </Pressable>
  );
}
