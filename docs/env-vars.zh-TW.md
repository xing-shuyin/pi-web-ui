# 環境變數

`PI_WEB_LOAD_TIMING=1` 可開啟歷史對話開啟的服務端分段計時（預設關閉，也接受 `true` / `on` / `yes`）。服務端控制台輸出 `[load-timing]` JSON，包含修復、SDK 開啟、分支校準、預覽、執行環境初始化、繫結和快照發送階段的耗時，不含會話路徑、ID 或正文。它不測量瀏覽器渲染及網路送達時間。詳見 [載入效能說明](loading-performance.zh-TW.md)。

## 裝置中心遠端桌面

遠端桌面參考 [krd](https://github.com/zzjcool/krd) 的原生捕獲與鍵鼠注入方式，畫面和輸入複用既有 WebSocket 中繼，無需 noVNC、VNC 服務或額外桌面埠。Windows 使用 GDI + SendInput；macOS 使用 Swift 原生助手，通過 ScreenCaptureKit `SCScreenshotManager` 捕獲、CoreGraphics 注入輸入，需要 macOS 14+、Swift CLI 和螢幕錄製許可權，控制時還需輔助功能許可權；Linux X11 使用 ffmpeg + xdotool，僅檢視時可不安裝 xdotool。Wayland 暫不支援，後續需接入 Desktop Portal。只讀許可權由後端強制執行。

舊 `PI_DEVICE_VNC_*` 環境變數已退役，不再讀取；無需配置 VNC 地址、埠、密碼、路徑或 noVNC 安裝目錄。詳見 `docs/device-center.md` 的「瀏覽器遠端桌面」。

## SSH 主機身份驗證

遠端工作區與官方 SFTP 外掛預設驗證 `~/.ssh/known_hosts`；`PI_WEB_SSH_KNOWN_HOSTS` 可指定另一份 OpenSSH known_hosts 檔案。未知、變更或被 `@revoked` 撤銷的主機金鑰在認證前拒絕，程式不會自動新增信任。支援普通/雜湊主機記錄、非預設埠與別名；當前不支援只依賴 `@cert-authority` 的主機證書信任，需要預配具體主機公鑰。

首次配置：通過伺服器控制台或管理員獨立核對主機指紋，然後在執行服務的同一賬戶下執行 `ssh -o StrictHostKeyChecking=ask -p <port> <user>@<host>`，僅在指紋一致時確認；也可把已獨立驗證的公鑰記錄預配到上述檔案。僅下載公鑰或執行 ssh-keyscan 不構成身份驗證。連線地址和埠須與記錄匹配。

## 本地配置頁（免命令列）

啟動後訪問 `http://127.0.0.1:<port>/setup`（**僅迴環地址可進**，非本機直接 403，不受 token 鑑權——忘口令時就靠它重設）。
可配：訪問口令 token、監聽地址 host、埠 port、Host 白名單、額外 Origin 白名單。
落盤 `<dataDir>/server-config.json`，優先順序：命令列旗標 > 環境變數 > 本檔案 > 預設值。
token 修改立即生效（含 WS）；host/port/白名單需 `pi-web-ui server restart` 後生效。
