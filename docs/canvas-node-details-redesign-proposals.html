💡 提示：支持快捷键 Esc 退出全屏或关闭；点击遮罩外部也可关闭。
方案架构 设计核心思想 解决“拥挤”的关键手段 适用工作场景 综合推荐度
方案 1: 工作台场景选项卡
(Workspace Tabs) 		信息分层与专注。顶层将“实录与插话”、“任务指令”、“契约审查”、“环境参数”解耦为独立 Tab。 独享 100% 宽度。长代码/终端输出不再被左栏 500px 挤压；看指令时也不受空日志干扰。 深耕重度开发、多轮审查、终端命令排错的综合协作流。 ★★★★★ (强烈推荐·体验最清爽)
方案 2: IDE 分屏与侧栏折叠
(IDE Split Pane) 		类似 VS Code 工作区。左侧极窄参数大纲（可一键收拢），右侧双窗格或全宽。 参数微缩 + 弹性收缩。折叠后中央区域独享 ~95% 视域，适合需要随时对照配置的用户。 既要频繁对照人设/契约、又要时刻盯着终端日志的高频调试场景。 ★★★★☆ (操作习惯类似 IDE)
方案 3: 场景自适应手风琴
(Smart Accordion) 		单列自上而下顺畅流式布局，各个模块采用智能折叠手风琴卡片。 智能感知状态折叠。运行态自动收起繁琐配置只留 1 行摘要，自动撑大日志区。 追求极简线性交互、不想频繁点选 Tab 的用户。 ★★★★☆ (单列自然顺畅)
方案 4: 全景三栏协同座舱
(3-Col Cockpit) 		三联画布局：[1. 输入契约] ➔ [2. 指令与交付] ➔ [3. 实录与插话]。 横向三维拉伸。充分利用全屏与 2K/4K 宽屏空间，全链路一览无余无需滚动寻找。 大屏多任务、重度依赖上游输入比对的高阶工作流。 ★★★☆☆ (小屏幕需换行适应)
