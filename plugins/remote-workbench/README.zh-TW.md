# 遠端工作臺

遠端工作臺複用宿主 `remoteSsh` 服務和 `<dataDir>/global-hosts.json`，與遠端工作區、SFTP 外掛共享 SSH 主機和加密憑據。外掛自己的分組、任務、命令片段和隧道配置獨立儲存，不復制 SSH 密碼。

## 主機與配置匯入

主機看板支援搜尋、分組及環境標記；環境和分組是工作臺後設資料，不改變宿主 SSH 憑據。健康檢查按需發起，返回負載、記憶體和磁碟指標；無法採集的指標不會偽造為正常值。

匯入 `~/.ssh/config` 時支援關鍵字大小寫、帶引號的路徑、多個主機別名、通配繼承、排除規則、首次賦值優先和 Include 檔案展開。Include 限制為 8 層、64 檔案、合計 1 MiB，防止迴圈和無界掃描。

`ProxyJump`、`ProxyCommand`、`Match` 等宿主無法完整表達的連線語義會明確顯示警告並阻止匯入。Include 失敗也會阻止不完整配置匯入。匯入時服務端重新掃描，不能靠修改瀏覽器提交引數繞過檢查。

## 終端與會話恢復

支援標籤、雙列、四格、自適應平鋪及獨立終端最大化。終端以位元組流寫入 xterm，保留 UTF-8 跨包字元；輸出有界排隊，並通過消費確認控制 SSH 輸出速度。

關閉工作臺面板與關閉終端是不同操作：面板解除安裝會脫離終端，顯式關閉終端會關閉 SSH 通道。同一瀏覽器標籤頁儲存不可猜測的恢復憑據，可在重新掛載時恢復；憑據不寫入共享主機配置。脫離會話有過期時間，外掛過載或服務重啟會清理記憶體中的 SSH 通道。

需要跨服務重啟保留遠端任務時，可選擇 tmux 模式，前提是目標機器已安裝 tmux。關閉 SSH 通道並不等於終止 tmux 內的程序。

終端提供緩衝區搜尋、引數化命令片段、多行貼上預覽和日誌匯出。廣播開啟時顯示實際目標清單；憑據輸入只發送給對應終端，不進入廣播或模型上下文。終端輸出本身仍可能包含遠端程式回顯，不能替代遠端程式的保密設定。

## 多機任務與 AI 命令

任務中心支援選擇主機、設定併發、檢視逐機狀態、取消任務和重試失敗主機。重試只執行選中的失敗項，不重複執行成功主機。執行態和配置寫入失敗會反饋給使用者，服務重啟後未完成任務標記為中斷，不自動重複執行命令。

`remote_term` 支援列出主機、探測、執行命令和按日誌 ID 分頁讀取輸出。命令執行使用有界輸出摘要，並將完整輸出儲存在有總量限制的本地日誌中；達到限制時會說明截斷情況。日誌可能包含命令及其輸出中的敏感資訊，不應將密碼直接放在命令列。

超時、使用者取消及外掛解除安裝會關閉執行通道並回收監聽。SSH 協議不能保證遠端程序及其所有子程序已經停止，結果會明確說明這一限制；有副作用的任務應在重試前核對遠端狀態。工作目錄使用 shell 引數引用，路徑中的空格和特殊字元不會改變命令結構。

主機的高危指令保護只用於攔截已知危險模式，不能完整理解任意 Shell、指令碼或 SQL；生產環境仍應使用最小許可權賬戶。

## 隧道與檔案

埠轉發監聽執行 pi-web-ui 服務的機器上的 `127.0.0.1`，並非訪問頁面的瀏覽器所在機器。支援儲存配置、啟動、停止、刪除、檢視狀態與錯誤、按配置重連。停止隧道會同時關閉監聽及已建立連線。

輕量檔案面板提供目錄瀏覽、有限大小的文本預覽和檔案上傳。上傳限制檔名與大小，使用排他建立，避免無意覆蓋已有遠端檔案。複雜傳輸繼續使用共享主機配置的 SFTP 外掛。

## 驗證與開發

- `npx vitest run tests/unit/remote-workbench-*.test.ts`：配置解析、執行取消與預算、終端歸屬及恢復、任務與隧道生命週期。
- `node tests/remote-workbench-ui-test.mjs`：獨立 Mock 後端的瀏覽器互動迴歸，不訪問真實 SSH 主機；Chrome 探測使用 `tests/lib/chrome.mjs`。
- 修改外掛程式碼時遞增 `manifest.json` 版本，並同步本地資料目錄中的外掛。若安裝目錄是指向本倉庫的目錄聯接，原始碼已同步，但服務端仍需過載外掛後才會使用新模組。
