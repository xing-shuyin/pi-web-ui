# 图片工具（image-toolkit）

🖼 一个把「压缩、裁剪、缩放、旋转、格式转换、批量导出、水印、滤镜」放在同一个画布上的图片工作台，
可以**直接读写当前工作区的图片**，另外给 AI 配了 4 个工具，让 agent 自己压缩/裁剪/缩放/加水印工作区里的图。

## 装法（插件不进 npm 包，随仓库分发）

```bash
# 从 GitHub 装（主仓库 plugins/image-toolkit 子目录）
pi-web-ui install xing-shuyin/pi-web-ui/plugins/image-toolkit

# 或已 clone 仓库时，直接复制目录（也是无网环境下的装法）
cp -r plugins/image-toolkit "<dataDir>/plugins/image-toolkit"
```

装完刷新浏览器，顶栏出现 🖼 图标；不需要时 `pi-web-ui uninstall image-toolkit` 或删目录即可
（插件目录一没，协议与 UI 痕迹全部消失，AI 工具也一起下架）。

## 界面

```
[导入图片] [从工作区] [清空]                                    [EN]
──────────────┬────────────────────────────────────┬──────────────────────
队列           │  − ＋ 1:1 适应 100%   300×400→192×256  │ 压缩│裁剪│尺寸│旋转│水印│滤镜│信息
▸ photo.png   │  ┌──────────────────────────┐      │ 输出格式 [WebP ▾] 1
  logo.png    │  │  棋盘格透明底 + 裁剪选框   │      │ 质量      ▓▓▓▓▓░░ 82
              │  │  （九宫格构图线 + 8 个把手）│      │ 目标体积  300 KB
              │  └──────────────────────────┘      │ [网页配图≤300KB][缩略图][只转格式]
              │  原始 4.2 MB → 输出 WebP ≈287 KB (-93%)│ [导出这张][导出全部ZIP][保存到工作区]…
```

- **左**：队列。每张图**各自一份参数**（可以各裁各的），「同步参数到全部」可一键铺开。
- **中**：画布。`Ctrl/⌘+滚轮`缩放、`适应` / `1:1`、`对比原图`（按住看原图）。框内按住可**平移选框**，框外压暗区按住可直接**拉出新选区**，8 个把手改宽高。
  裁剪 tab 下选框带三分线与 8 个把手，坐标基于「旋转+任意角度外扩后」的画面，面板里的
  左/上/宽/高与选框永远一致（锁比例时联动）。
- **右**：七个参数页 + 底部动作区。动作区里还有 `撤销/重做`（`Ctrl+Z` / `Ctrl+Shift+Z`）与
  `精确计算`（按真实输出分辨率编码一次，得到准确体积；平时显示的是按像素比折算的「≈ 估算」）。

功能一览：

| 页 | 能力 |
| --- | --- |
| 压缩 | 输出格式（保持原格式 / JPEG / WebP / PNG / AVIF，浏览器编不了的自动禁用）、质量滑杆、**目标体积**（二分逼近质量，质量压到底还超标就按面积降尺寸）、透明转 JPEG 的底色、文件名后缀、常用预设 |
| 裁剪 | 自由比例 / 1:1 / 4:3 / 3:2 / 16:9 / 9:16 / 3:4 / 2:3 / **自定义 W:H**（自己填两个数，如 21:9）、**按原图比例**（一键还原成当前图片的宽高比并铺满）、数值输入、居中 / 最大 / 重置、三分线开关；**形状**：矩形 / 圆角矩形（半径可调）/ 椭圆 / 圆形（自动锁 1:1）/ 菱形 / 心形 / 星形——非矩形形状框外导出为透明 |
| 尺寸 | 长边 / 宽 / 高 / 百分比四种模式、不放大（显式同时给宽高则以精确尺寸为准）、插值质量、256/512/1080/1920/3840 预设 |
| 旋转 | 左右 90°、180°、水平/垂直翻转、任意角度（外扩画布 + 填充色） |
| 水印 | 文字（`{name}` `{date}` `{w}` `{h}` 变量、字号按短边百分比、颜色、透明度、旋转）或图片水印（缩放百分比）；九宫格定位或**平铺**（间距可调） |
| 滤镜 | 亮度/对比度/饱和度/色相/伽马/灰度/复古/反色/模糊/锐化/暗角 + 圆角、边框（宽度与颜色） |
| 信息 | 格式/尺寸/体积/宽高比/百万像素/透明通道、EXIF（设备/镜头/光圈/快门/ISO/焦距/时间/GPS）、亮度直方图、主色调（点击复制 hex）、当前输出摘要 |

导入方式：`导入图片`、整窗**拖放**、`Ctrl+V` 粘贴剪贴板里的图、或「从工作区」挑选（带缩略图列表）。
导出方式：`导出这张`（下载）、`导出全部（ZIP）`（store-only ZIP，不二次压缩）、
`复制到剪贴板`（PNG，可以直接粘进对话输入框）、`保存到工作区`（可覆盖 / 自动改名）。

## 原理与分工

**拖动跟手**：裁剪拖动只挪覆盖层（框外遮罩是四块固定色块 + 形状用一条 SVG 路径），**不重渲染画布**——裁剪 tab 的预览本来就是未裁的全图，重渲染纯浪费；裁剪选框的回调走 rAF 合批，一帧只应用最后一次指针位置。预览的渲染尺度也按「屏幕实际需要的像素比」再收一次（`viewScale × dpr`，下限为预算的 35%），大图不再是每次都按预算上限硬渲。实测 3000×2000 开满滤镜时：单次预览渲染按显示需要 28ms，旧做法（按预算上限）206ms。

- **像素处理全在浏览器**（Canvas + `ctx.filter` + 少量 ImageData 逐像素）：零依赖、格式支持最全
  （PNG/JPEG/WebP/GIF/AVIF 都看浏览器的解码器），预览用代理分辨率（适应窗口 2.6MP、放大看细节 12MP），
  导出走全分辨率，两条路共用同一份渲染管线（`client/pipeline.mjs`），所以「所见即所得」。
- **服务端只做浏览器做不了的两件事**（`index.mjs`）：
  1. **工作区读写**——`GET /ws/list|image|probe`、`POST /ws/save`、`GET /ws/settings`，
     全部走 `host.fs`（路径锚定当前工作区、越界拒绝）。读图与存图走**原始字节**
     （`/ws/image` 直接喂 `<img>`，存图用 `POST` 裸 body），不经过 base64，也不吃
     `express.json` 的 10MB 上限。
  2. **AI 工具**——见下。

参数与像素分离：`item.state` 是纯 JSON（可快照 → 撤销/重做、复制到全部），渲染是它的纯函数，
所以预览、精确估算、导出、批量走的是同一套代码，参数一致结果必然一致。

## 给 AI 的 4 个工具

| 工具 | 作用 |
| --- | --- |
| `image_info` | 读工作区图片的格式/尺寸/体积/宽高比/透明/EXIF；给 `dir` 就递归扫目录（深度 3、上限 200 张）；`details:true` 额外给直方图峰值与主色 |
| `image_transform` | 缩放（宽/高/长边/百分比）、裁剪、旋转 90°/任意角度、翻转、逐像素调色（亮度/对比度/饱和度/色相/伽马/灰度/复古/反色/模糊/锐化/暗角）；支持 `paths` 批量 |
| `image_compress` | 压缩：转格式 + 质量 + **`targetKB`**（二分逼近，必要时降尺寸） |
| `image_watermark` | 叠图片水印（九宫格位置 / 透明度 / 缩放 / 平铺） |

约定：默认**不动原文件**（写 `<名字><后缀>.<新扩展名>`，同名自动 `-1`、`-2`，除非 `overwrite:true`）；
批量时逐项报 `✅/❌`，单项失败不拖累其它项；写盘后 `host.notify` 提示，文件树由主应用 watcher 自动刷新。

服务端能解/能写的格式是 **PNG / JPEG / BMP**：

- PNG / BMP 用插件自带的**纯 JS 编解码**（`core/`，只依赖 `node:zlib`，零安装）；
- JPEG 需要一次性装**纯 JS** 的 `jpeg-js`（`host.ensureDeps` 自动装到插件目录，没有原生编译；
  设置里可以关掉，关掉后 AI 只处理 PNG/BMP）；
- WebP / GIF / AVIF 的像素处理只在视图里（浏览器的解码器），工具遇到这些格式会**明确告诉你**
  去视图处理，而不是静默失败。

## 设置（⚙ 面板 → 界面插件 → 图片工具）

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 默认输出格式 | keep | 新导入图片的初始格式（keep = 跟随原格式，默认质量 0.82） |
| 默认质量 | 0.82 | 只有 JPEG/WebP/AVIF 用得上 |
| 长边上限 | 0 | 非 0 时新导入图片默认按长边缩放到这个值 |
| 输出文件名后缀 | -min | 导出/保存到工作区时拼在文件名后 |
| 覆盖同名文件 | 关 | 关掉时同名自动加 `-1`、`-2`，绝不误删 |
| 让 AI 处理图片 | 开 | 关掉后 agent 看不到 `image_*` 工具（视图不受影响） |
| 允许安装纯 JS 编解码包 | 开 | 服务端处理 JPEG 需要它；关掉则 AI 只能处理 PNG/BMP |

## 限制（有意为之）

- 服务端不处理 SVG（矢量转位图交给浏览器）；隔行（Adam7）PNG 服务端不解码（视图能处理）。
- 文字水印只在视图里（用浏览器字体）；AI 的 `image_watermark` 只能叠图片水印。
- AVIF 能不能用取决于浏览器有没有编码器（Chrome 多数只能解不能编，下拉里会标「当前浏览器不支持该格式编码」）。
- 预览里的**锐化/暗角/伽马**按代理分辨率算（导出才是全分辨率），极高倍放大时预览与成片会有细微差别。
- 目标体积压缩只对 JPEG/WebP 有意义（PNG 是无损的，工具会走无损路径）。
- **形状抠图必须用能存 alpha 的格式**：形状外的区域只能是「透明」或「底色」二选一，**JPEG 只能给底色**。插件会自己盯着这件事——如果你的图是 JPEG、格式还停在「保持原格式」，选形状时会**自动改成 PNG** 并弹提示；如果你显式选了 JPEG，面板会给警告 + 一个「改用 PNG（透明）」按钮，状态条也会写明「形状外填底色 #ffffff」。
- 非矩形裁剪形状的「框外」是透明：导出 PNG/WebP 才是透明底，导 JPEG 会用底色填满（不透明格式没有 alpha）。
- 形状是「按外接矩形变形」的：同一个星形在 1:1 和 16:9 下会横竖拉长——想不变形就选合适比例。
