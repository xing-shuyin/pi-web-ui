# QQ 機器人與工作臺 (QQBot Plugin)

> QQ 機器人外掛，基於騰訊官方開放平臺 QQBot WebSocket 出站長連線，支援雙向會話對話（零公網 IP / 免反代）、結構感知 Markdown 智慧分塊、白名單安全准入與頻道/群聊訊息推送。基礎文字與媒體收發使用 Node 內建能力；自動語音回覆按需安裝 SILK 編碼元件。

## 功能特性

- 🤖 **QQBot 官方 WebSocket 出站長連線雙工對話**：基於騰訊官方開放平臺 QQBot Gateway 協議，客戶端主動發起長連線，**零公網 IP、免域名備案、免反向代理、免開放入站埠**，在區域網或個人電腦即可即開即用！
- 📦 **結構感知 Markdown 分塊**：針對 QQ 訊息長度限制，採用類似 `dsh-im` 的智慧分塊演算法，保證程式碼塊（\`\`\`）自動閉合與語法高亮不破損。
- ⚡ **斜槓快捷指令**：支援 `/help`、`/clear` 或 `/new`（清空上下文開啟全新對話）、`/status`（檢視機器人線上指標）、`/abort`（同 `/stop`、`/8`，中止當前目的地的任務；失敗會明確提示）。
- 🛡️ **安全白名單控制**：支援設定允許對話的 QQ OpenID / 使用者 ID 白名單，未授權人員友好攔截，防止 Bot 被陌生人濫用。
- 💬 **被動訊息引用與多端支援**：支援 QQ 頻道子頻道（@機器人）、QQ 群聊（@機器人）以及單聊好友訊息，自動關聯 `msg_id` 被動回覆。
- 🛠️ **AI 工具**：向 AI 助手註冊 `qq` 工具，AI 可自主向 QQ 頻道推送訊息與通知。
- 🖼️ **富媒體雙向（圖片/語音/影片/檔案）**：
  - **收**：QQ 發來的附件（事件裡的 `attachments`，騰訊 CDN、有實效）下載後落到工作區
    `.pi-qq-media/`。PNG/JPEG/GIF/WebP 圖片以 `imageData` 附件進入模型（最多 8 張、單張 10MiB、合計 20MiB）；其他圖片格式明確提示轉換。檔案、音訊和影片作為路徑引用附件傳給宿主，不承諾模型能直接理解音影片。語音優先下載 `voice_wav_url`（按 WAV 命名），保留平臺 ASR 文本，即使下載失敗或關閉落地；沒有平臺 ASR 時明確說明外掛不提供轉寫，請補充文字或使用轉寫工具。單件下載上限 25MiB，超限/下載失敗降級為佔位文字（絕不吞訊息）；
    設定裡可開關「接收圖片/檔案落地」。
  - **發**：`qq` 工具新增 `image` / `file`（本地路徑或 http(s) URL）與 `user_openid` /
    `group_openid` 目標。鏈路 = `POST /v2/{users|groups}/{openid}/files`
    （本地檔案 ≤ 5MB 走 base64 `file_data`，更大自動走 `upload_prepare` → 分片 PUT →
    `upload_part_finish` → 合併拿 `file_info`）→ `msg_type=7` + `media.file_info`。
    超過軟限制（圖片 20MB / 影片 30MB / 語音 20MB）由 QQ 側降級為檔案卡片。
  - **頻道限制**：QQ 頻道子頻道只接受**公網 http(s) URL** 的 `image` 欄位，本地檔案沒有
    上傳通道 —— 要麼先用單聊/群聊發，要麼給公網連結（工作臺會直接報錯提示）。

群聊和頻道按「使用者 + 目的地 + thread（若事件提供）」隔離會話；單聊按使用者隔離。`/new`、`/clear` 與 `/cwd` 切換遞增該 peer 的會話 epoch，同時更換宿主 accountId，避免複用舊上下文。命令先於附件下載處理，`/stop` 不等待媒體下載。回執中的真實 conversationId 用於續聊，穩定 runId 用於接管後的事件歸屬；回執前事件只有匹配該 runId 才重放。同一會話執行中再次發訊息會提示等待或中止。網頁開啟該 QQ 會話並主動續聊時，最終助手回覆也會回傳對應單聊、群或頻道；回傳繫結使用穩定 SDK `sessionId`，保留目的地與當前會話 epoch 校驗。`/new` 等重置後舊會話不再回傳，不按區域性 `c1` 猜測聯絡人；多人繫結同一網頁會話時存在歧義，不自動回傳。`bindActive` 顯式開啟時會使用宿主當前會話，同一會話已有執行時拒絕覆蓋。

網頁發起且沒有通道執行標記的任務，QQ `/stop` 會提示到網頁端停止，不按區域性會話編號中止。超出 QQ 被動回覆視窗時嘗試主動訊息傳送，實際受平臺許可權和額度限制；投遞失敗會顯示在 QQ 面板狀態中。

## 自動語音回覆

QQ 工作臺 →「機器人憑證與進階設定」→「自動回覆語音」，選擇「語音回覆」或「語音和文字」，再選擇引擎、音色和語速，儲存即可。預設維持文字回覆。

- `builtin` 使用伺服器的系統語音，無需 TTS 外掛。Windows 使用已安裝的系統音色，macOS 使用 `say`，Linux 需有 `espeak-ng` / `espeak`。
- 安裝並啟用 TTS 外掛後，可以選擇 `doubao-tts`、`deepseek-tts` 及其音色；其他外掛向統一 TTS 中心註冊的引擎也會出現在列表中。憑據在提供該引擎的外掛中配置。
- 單聊、群聊及已繫結網頁會話的最終回答支援語音；頻道、指令回執和進度提示使用文字。長回覆朗讀開頭，同時保留完整文字；語音生成、轉碼或傳送失敗時自動回退到完整文字，原因可在進階設定檢視。
- 首次合成 QQ 語音時按需安裝 `silk-wasm`；AAC 等壓縮音訊按需安裝 `ffmpeg-static`。系統 WAV 只需 SILK 編碼元件。

引擎註冊、系統音色、API 與取消規則見 [`docs/architecture-tts.md`](../../docs/architecture-tts.zh-TW.md)。

## 配置指南

1. 開啟 [QQ 開放平臺](https://q.qq.com/) 並註冊/登入開發者賬號；
2. 進入「機器人」管理後臺，建立機器人應用；
3. 獲取機器人的 **AppID** 與 **ClientSecret**；
4. 在機器人設定中配置好機器人名稱、頭像以及許可權列表；
5. 在 pi-web-ui 的 QQ 面板點選「⚙️ 配置憑證」，填入 AppID 與 ClientSecret，勾選「啟用 QQ 機器人雙向會話對話服務」即可！

## 連線狀態排障

- **`Failed to obtain QQ Gateway URL: 介面呼叫超過頻率限制 (100017)`**：`/gateway` 被限流，幾乎都來自重連風暴或多宿主搶佔，不是訊息量大。
  - 同一 AppID 只允許一條 Gateway 長連。外掛會在資料目錄 `qq/bot-<appId>.lock` 寫單例項鎖：第二個宿主（例如 dev + 生產、或另一個 `npm run dev`）只會報「已在另一個宿主程序連線」並退避等待，不再重複長連；停掉佔用方後會自動接管。
  - 重連是指數退避（5s→10s→…→120s）；命中 100017 時至少等 60s，且 `/gateway` 的 URL 與 access_token 在有效期內複用，不會每次重連都重新拉取。
  - 仍需手動立即重試時點「⚡ 啟停服務」，會強制重置退避並重新連線。
