# Wallpaper Engine 動態桌布外掛 (v0.3.0)

把本機 **Wallpaper Engine** 的創意工坊桌布無縫融入到 `pi-web-ui` 的對話介面後方，配合液態毛玻璃磨砂效果、透明度微調、WebGL2 場景渲染、音訊頻譜聯動與自動輪播。

參照 [dsh-wallpaper-engine](https://github.com/elysia395/dsh-wallpaper-engine) 方案，專為 `pi-web-ui` 定製。**不向模型註冊額外工具或提示詞，不增加任何 Token 開銷。**

---

## 核心特性

- 🎮 **全盤 Steam 庫深度檢索**：自動讀取 Windows 登錄檔與 Steam 配置檔案 `libraryfolders.vdf`，自動探測全盤跨分割槽各庫中的 Wallpaper Engine 創意工坊桌布（AppID `431960`）與預設桌布。
- 🎬 **全格式桌布支援**：
  - **Video（影片）**：支援 HTTP 206 Range 分片流式載入，高畫質 MP4 / WebM 流暢迴圈與靜音切換。
  - **Scene（場景）**：整合 WebGL2 即時渲染引擎（基於 `webwallgl`），支援 `.pkg` 資源包解析、粒子系統、骨骼動畫與著色器動態光影。
  - **Web（網頁）**：沙箱 `<iframe>` 隔離掛載，內建 Wallpaper Engine 常用屬性與事件墊片注入。
  - **Image（靜態圖）**：JPG / PNG / WebP 全屏高質量居中自適應渲染。
- 🎵 **音樂頻譜響應聯動**：內建聲學頻譜波形模擬與採集器，支援將音訊律動即時注入到具備音訊反應能力的 Web 與 Scene 場景桌布中。
- ⭐ **桌布收藏與自動輪播**：
  - 點選桌布卡片右下角的 **⭐** 即可快速加入/移除收藏，並支援專屬“⭐ 收藏”分類標籤；
  - 支援設定 **5分鐘 / 15分鐘 / 30分鐘 / 1小時** 自動定時輪播，也可在抽屜頂部點選 **🎲 切下一張** 立即隨機切換。
- 📤 **外觀預設匯入與匯出**：支援一鍵將當前啟用桌布、毛玻璃模糊度、不透明度與收藏夾配置匯出為獨立 JSON 快照，或從剪貼簿匯入分享方案。
- 🧊 **液態毛玻璃效果（Liquid Glass）**：通過 CSS 變數動態驅動介面各層磨砂質感，支援模糊半徑（0-32px）與介面底色不透明度（40%-100%）即時無縫調節。
- 🕹️ **互動與穿透模式**：支援開啟“允許互動”模式，讓滑鼠可以穿透聊天對話區與背景中的 Web / Scene 動態桌布產生即時互動。
- ⚡ **智慧能耗管理**：
  - 可設定 **30 FPS / 60 FPS / 無限制** 幀率上限，兼顧流暢與顯示卡省電。
  - 頁面切入後臺隱藏時，自動掛起影片播放與 WebGL 渲染迴圈，絕不搶佔程式設計與模型生成算力。
- 🪟 **沉浸式桌布抽屜**：頂欄一鍵展開抽屜面板，支援按標題/標籤即時搜尋、多維度分類篩選（全部/收藏/影片/場景/網頁/靜態圖）、網格多頁翻頁瀏覽（大幅降低海量桌布 DOM 與圖片併發負載）、封面原始縱橫比 1:1 保真渲染（不壓縮裁剪畫面，搭配毛玻璃氛圍底光）與即時切換。

## 支援的桌布型別對照

| 型別                    | 說明                         | 支援情況    | 渲染機制                                   |
| ----------------------- | ---------------------------- | ----------- | ------------------------------------------ |
| **Video（影片）**       | MP4 / WebM / M4V             | ✅ 完全支援 | 原生 `<video>` 硬體加速，HTTP 206 流式分片 |
| **Scene（場景）**       | 2D/3D 動態場景 (`.pkg`)      | ✅ 完全支援 | `webwallgl` WebGL2 即時渲染，失敗平滑降級  |
| **Web（網頁）**         | HTML / JS / CSS 網頁桌布     | ✅ 完全支援 | 沙箱隔離 `<iframe>` + WE API 墊片          |
| **Image（靜態圖片）**   | JPG / PNG / WebP             | ✅ 完全支援 | 全屏自適應渲染與縮圖                       |
| **Application（應用）** | 需啟動外部 `.exe` 的程式桌布 | ❌ 不支援   | 自動過濾，不進入候選列表                   |

## 外掛目錄結構

```text
plugins/wallpaper-engine/
├── manifest.json            # 外掛清單（宣告許可權、設定項與頂欄按鈕，v0.3.0）
├── index.mjs                # 服務端：Steam 路徑掃描、後設資料解析、流式影片、Scene.pkg 與 Web 安全沙箱路由
├── client/
│   ├── entry.mjs            # 客戶端：全能渲染引擎（Video/Scene/Web）、音訊響應、定時輪播與抽屜元件
│   └── styles.mjs           # 樣式：毛玻璃 CSS 變數覆蓋、穿透互動、收藏狀態與抽屜面板樣式
└── README.md                # 外掛完整技術說明文件
```

## 協議與 API 路由

所有 HTTP 介面掛載於 `/plugins-api/wallpaper-engine/api/*`：

| 路由                        | 方法   | 功能描述                                               |
| --------------------------- | ------ | ------------------------------------------------------ |
| `/api/wallpapers`           | `GET`  | 獲取本機已掃描到的所有桌布列表、當前啟用狀態與收藏集合 |
| `/api/rescan`               | `GET`  | 清理服務端快取，重新全量掃描各磁碟驅動器的 Steam 庫    |
| `/api/preview?id=:id`       | `GET`  | 讀取桌布縮圖（帶 24 小時 HTTP 客戶端快取）             |
| `/api/media?id=:id`         | `GET`  | 讀取影片或主檔案（支援 HTTP 206 Partial Content 分片） |
| `/api/pkg?id=:id`           | `GET`  | 讀取 Scene 場景桌布二進位制 `scene.pkg` 資料包         |
| `/api/project?id=:id`       | `GET`  | 讀取桌布原始 `project.json` 配置清單                   |
| `/api/web?id=:id&file=:rel` | `GET`  | 網頁桌布靜態資源安全沙箱服務（嚴格路徑校驗防逃逸）     |
| `/api/favorite`             | `POST` | 切換指定桌布的收藏狀態（收藏/取消收藏）                |
| `/api/presets`              | `GET`  | 匯出當前桌布選擇與毛玻璃外觀配置預設 JSON              |
| `/api/presets`              | `POST` | 匯入並應用外部外觀配置預設 JSON                        |
| `/api/active`               | `GET`  | 獲取當前使用的桌布、輪播設定及毛玻璃引數               |
| `/api/active`               | `POST` | 儲存當前桌布與引數變更，並向其它已連線標籤頁廣播同步   |

## 使用方法

1. 確保電腦已安裝 Steam 並訂閱了 Wallpaper Engine 創意工坊桌布；
2. 啟動 `pi-web-ui`，在頂部導航欄右上角點選 **🖼️ 桌布** 圖示；
3. 在展開的抽屜中瀏覽已識別的桌布（可通過分類標籤切換“全部”、“⭐ 收藏”、“影片”、“場景”、“網頁”或“靜態圖”）；
4. 點選卡片上的 **☆** 將喜歡的桌布加入收藏，點選卡片主體即可立即應用；
5. 可在抽屜頂部根據個人喜好調節：
   - **模糊度與不透明度**：微調出最舒適的透光磨砂質感；
   - **自動輪播**：選擇輪播間隔時間（如每 15 分鐘），或點選“切下一張”手動換桌布；
   - **音樂頻譜**：開啟後具備音訊反應能力的桌布將跟隨聲音律動；
   - **允許互動**：開啟後滑鼠可在對話區空隙與背景互動；
   - **匯出/匯入預設**：一鍵儲存或分享外觀方案；
   - **關閉桌布**：隨時一鍵還原為原生實色介面。
