# 洛雪音樂 (LX Music) 介面外掛

一個無縫嵌入 `pi-web-ui` 的全功能專業音樂播放器外掛。

## 🌟 核心特性全覽

- **多平臺聚合檢索**：內建網易雲、QQ音樂、酷我、酷狗、咪咕音樂搜尋源，一鍵無縫切換。
- **各平臺獨立官方排行榜**：支援網易雲、QQ音樂、酷我、酷狗四大平臺獨立排行榜切換瀏覽！覆蓋網易雲熱歌榜/飆升榜/新歌榜/原創榜/說唱榜、QQ音樂流行指數榜/熱歌榜/新歌榜/飆升榜、酷狗TOP500/飆升榜/抖音熱歌榜、酷我熱歌榜/飆升榜/新歌榜/DJ榜等各平臺全部官方權威榜單。
- **全平臺精選歌單與匯入**：全新「🎶 歌單」頻道，支援按平臺（網易雲/QQ音樂/酷狗/酷我）與流派分類（全部/流行/華語/搖滾/民謠/輕音樂/影視等）瀏覽各大平臺海量優質歌單；支援點選卡片檢視完整歌單詳情、一鍵播放全部；支援輸入歌單分享連結或歌單 ID 極速解析匯入！
- **桌面畫中畫懸浮歌詞（Picture-in-Picture）**：基於現代瀏覽器畫中畫引擎，獨立置頂小浮窗，即時跟隨滾動高亮，切換到編輯器或其它軟體寫程式碼也能輕鬆看歌詞。
- **點選或雙擊播放**：在搜尋、榜單、收藏、歷史與播放佇列中，雙擊歌曲行或點選行右側播放按鈕即可立即起播。
- **逐行動態滾動歌詞**：LRC 歌詞解析引擎，當前播放句居中高亮放大，支援點選歌詞時間行直接跳轉（Seek）播放。
- **三大播放模式**：支援「🔁 列表迴圈」、「🔀 隨機播放」、「🔂 單曲迴圈」自由切換。
- **重新整理自動恢復**：播放佇列、收藏、搜尋結果與關鍵詞、榜單列表、當前歌曲及進度、音量、音質、播放模式和所選平臺儲存在瀏覽器本地，按部署路徑隔離；重新整理後點擊播放可從上次進度繼續，播放連結重新獲取。進度每 3 秒儲存，暫停、切走頁面時立即儲存。瀏覽器儲存失敗會顯示提示。
- **播放記錄**：成功播放後自動記錄，按平臺及歌曲去重，最近播放優先，保留最近 500 首；“播放記錄”頁支援重新播放和加入佇列。清除瀏覽器站點資料會清除這些本地記錄；收藏和自定義音源另有服務端資料目錄儲存。
- **播放佇列與抽屜管理**：隨時檢視當前播放佇列歌曲清單，支援一鍵追加、單獨刪除與清空。
- **“我喜歡”收藏夾**：歌曲行點選心形按鈕（❤️ / 🤍）即時加入收藏，資料持久化儲存在資料目錄，升級不丟。
- **一鍵下載歌曲檔案**：點選歌曲行「⬇️ 下載」按鈕，自動以 `歌曲名 - 歌手.mp3` 儲存到本地裝置。
- **音質檔位切換**：支援選擇 128k (標準)、320k (高品質) 與 FLAC (無損)。
- **全域性鍵盤快捷鍵**：
  - `Space`：播放 / 暫停
  - `ArrowLeft` / `ArrowRight`：快退 5 秒 / 快進 5 秒
  - `Ctrl + ArrowLeft` / `Ctrl + ArrowRight`：上一首 / 下一首
  - `ArrowUp` / `ArrowDown`：音量微調 (+5% / -5%)
- **六音等自定義音源指令碼執行環境**：相容社群六音等第三方音源指令碼（User API），支援直接貼上原始碼或輸入線上 URL 下載（只從你給的原始 URL 拉取，不再經 ghproxy/ghfast 等第三方映象回退）。指令碼在 `node:vm` 中執行且不注入宿主 realm 引用（`Buffer`/`URL`/`fetch`/`TextEncoder` 等宿主內建不在指令碼全局裡），但 **`node:vm` 不是安全邊界**：只用於承載你自願匯入的指令碼，不要匯入來源不明的指令碼；真需要強隔離請把服務端跑在受限容器內。
- **常駐後臺播放**：切回 AI 對話或開啟設定面板時，音樂保持持續播放不中斷。
- **系統媒體鍵整合**：支援 `navigator.mediaSession`，可使用鍵盤多媒體鍵（播放/暫停/上一曲/下一曲）及系統鎖屏控制元件。
- **AI 智慧體對話點歌**：註冊 `music_control` Agent Tool，在主聊天介面對 AI 說“播放一首周杰倫的晴天”，AI 將自動檢索並即時廣播給播放器起播。
