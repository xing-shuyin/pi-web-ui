# 洛雪音乐 (LX Music) 界面插件

一个无缝嵌入 `pi-web-ui` 的全功能专业音乐播放器插件。

## 🌟 核心特性全览

- **多平台聚合检索**：内置网易云、QQ音乐、酷我、酷狗、咪咕音乐搜索源，一键无缝切换。
- **各平台独立官方排行榜**：支持网易云、QQ音乐、酷我、酷狗四大平台独立排行榜切换浏览！覆盖网易云热歌榜/飙升榜/新歌榜/原创榜/说唱榜、QQ音乐流行指数榜/热歌榜/新歌榜/飙升榜、酷狗TOP500/飙升榜/抖音热歌榜、酷我热歌榜/飙升榜/新歌榜/DJ榜等各平台全部官方权威榜单。
- **全平台精选歌单与导入**：全新「🎶 歌单」频道，支持按平台（网易云/QQ音乐/酷狗/酷我）与流派分类（全部/流行/华语/摇滚/民谣/轻音乐/影视等）浏览各大平台海量优质歌单；支持点击卡片查看完整歌单详情、一键播放全部；支持输入歌单分享链接或歌单 ID 极速解析导入！
- **桌面画中画悬浮歌词（Picture-in-Picture）**：基于现代浏览器画中画引擎，独立置顶小浮窗，实时跟随滚动高亮，切换到编辑器或其它软件写代码也能轻松看歌词。
- **点击或双击播放**：在搜索、榜单、收藏、历史与播放队列中，双击歌曲行或点击行右侧播放按钮即可立即起播。
- **逐行动态滚动歌词**：LRC 歌词解析引擎，当前播放句居中高亮放大，支持点击歌词时间行直接跳转（Seek）播放。
- **三大播放模式**：支持「🔁 列表循环」、「🔀 随机播放」、「🔂 单曲循环」自由切换。
- **刷新自动恢复**：播放队列、收藏、搜索结果与关键词、榜单列表、当前歌曲及进度、音量、音质、播放模式和所选平台保存在浏览器本地，按部署路径隔离；刷新后点击播放可从上次进度继续，播放链接重新获取。进度每 3 秒保存，暂停、切走页面时立即保存。浏览器存储失败会显示提示。
- **播放记录**：成功播放后自动记录，按平台及歌曲去重，最近播放优先，保留最近 500 首；“播放记录”页支持重新播放和加入队列。清除浏览器站点数据会清除这些本地记录；收藏和自定义音源另有服务端数据目录存储。
- **播放队列与抽屉管理**：随时查看当前播放队列歌曲清单，支持一键追加、单独删除与清空。
- **“我喜欢”收藏夹**：歌曲行点击心形按钮（❤️ / 🤍）即时加入收藏，数据持久化保存在数据目录，升级不丢。
- **一键下载歌曲文件**：点击歌曲行「⬇️ 下载」按钮，自动以 `歌曲名 - 歌手.mp3` 保存到本地设备。
- **音质档位切换**：支持选择 128k (标准)、320k (高品质) 与 FLAC (无损)。
- **全局键盘快捷键**：
  - `Space`：播放 / 暂停
  - `ArrowLeft` / `ArrowRight`：快退 5 秒 / 快进 5 秒
  - `Ctrl + ArrowLeft` / `Ctrl + ArrowRight`：上一首 / 下一首
  - `ArrowUp` / `ArrowDown`：音量微调 (+5% / -5%)
- **六音等自定义音源脚本沙箱**：兼容社区六音等第三方音源脚本（User API），通过 Node.js 沙箱安全高效运行，支持直接粘贴源码或输入在线 URL 自动镜像下载。
- **常驻后台播放**：切回 AI 对话或打开设置面板时，音乐保持持续播放不中断。
- **系统媒体键集成**：支持 `navigator.mediaSession`，可使用键盘多媒体键（播放/暂停/上一曲/下一曲）及系统锁屏控件。
- **AI 智能体对话点歌**：注册 `music_control` Agent Tool，在主聊天界面对 AI 说“播放一首周杰伦的晴天”，AI 将自动检索并实时广播给播放器起播。
