# 📓 筆記（notes 外掛）

前沿閃念速記 · 現代卡片流 · 定時提醒 · 日曆檢視，裝成 pi-web-ui 的介面外掛：

- **極簡雙 Tab**：只保留「筆記」與「日曆」兩個 Tab，介面純粹剋制。
- **無標題隨手記**：直接記錄文字與想法，打字即記，不需要絞盡腦汁起標題，秒速捕捉靈感；支援 Markdown 渲染（段落、列表、程式碼、待辦核取方塊互動）。
- **額外設定提醒**：每一條筆記都可以順手設定提醒（1小時後、今晚、明天、自定義時間、重複檔位），到點通過服務端長輪詢通知（站內彈窗 / 桌面通知 / 提示音）。卡片上展示提醒狀態膠囊，支援快捷推遲與調整。
- **就地快速編輯（Inline Editing）**：點選卡片上的 ✏️ 或雙擊正文，原位展開內聯編輯，按 `Ctrl+Enter` 瞬間就地儲存，按 `Esc` 放棄，零跳轉、零換欄。
- **日曆檢視**：42 格月曆檢視，把設定了提醒的筆記與日程按天展示，點選某天可檢視當天清單，並支援一鍵「在這一天記筆記」（自動預置該天提醒）。
- **Markdown 映象**（可選，預設關）：在設定裡開開關 + 填一個絕對目錄，每次改動把每篇筆記寫成 `.md`、另生成 `_todos.md` / `_reminders.md` 彙總 —— 給 Obsidian / git 用。
- **一個入口**：頂欄 **📓 筆記** 開啟**可自由拖拽的全域性浮窗**（位置/尺寸/開合/最小化狀態記憶，
  可縮成帶角標的小貼片），窗口裡的 **⚙** 開啟設定覆蓋層（通知開關 / 語言 / 匯入匯出 / 重置位置）。
  本外掛**沒有獨立檢視 tab**（`manifest.view: false`）—— 浮窗就是它的全部介面。
- **AI 也能寫**：5 個工具 + 4 個斜槓命令。

## 安裝

設定 →「介面外掛」→「外掛市場」裡的 **筆記** 一鍵安裝；或：

```bash
pi-web-ui install xing-shuyin/pi-web-ui/plugins/notes
```

裝完重新整理頁面：頂欄出現 📓 筆記（拖不到？見下面「介面佈局」）。

## 用法

| 做什麼          | 怎麼寫                                                                                                                                 |
| --------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 隨手速記        | 頂部輸入框直接寫文字內容，按 `Ctrl+Enter`（或點選「記下」）即刻存入；支援 `#標籤` 自動歸類                                             |
| 額外設提醒      | 輸入框下方點選 `⏰ 設提醒`，快捷選擇「1小時後 / 今晚 20:00 / 明天 09:00 / 自定義時間」；若文本含時間詞還會智慧提示一鍵設提醒           |
| 就地編輯        | 滑鼠懸浮筆記卡片點選 ✏️（或雙擊正文）→ 原位直接修改，按 `Ctrl+Enter` 立即儲存，按 `Esc` 取消                                           |
| 推遲提醒        | 筆記卡片上的 ⏰ 膠囊點選：快捷推遲 10 分鐘、推遲到明天、或修改/移除提醒                                                                |
| 快速捕獲        | 快捷鍵 `Ctrl/Cmd+Alt+N`（開啟浮窗並聚焦輸入框）；斜槓命令 `/note`、`/todo`、`/remind`                                                  |
| 日曆排期        | 切換到「日曆」Tab：檢視當月每天的提醒與事項；點選某天可直接「在這一天記筆記」                                                          |
| 批次整理        | 浮窗 ⚙（設定覆蓋層）裡匯出 JSON / Markdown、匯入 JSON（合併或整庫覆蓋）                                                                |
| 映象給 Obsidian | 設定 →「介面外掛」→ 筆記 → 勾「映象成 Markdown 檔案」+ 填絕對目錄（首次寫入瀏覽器會要一次目錄授權）；也可 `/notes-mirror` 手動同步一次 |

### 給 AI 用（設定 →「工具」頁可開關）

單個工具 `notes`，用 `op` 分流（讀之前先 `op=list` 拿 id）：

| `op`          | 作用                                                                                                                   |
| ------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `list`        | 讀筆記/待辦/提醒（帶 id；支援 `kind` / `query` / `tag` / `include_done` / `limit`）                                    |
| `note_add`    | 記一條筆記（Markdown 正文）                                                                                            |
| `note_update` | 按 id 改/刪筆記（`append` 追加正文）                                                                                   |
| `todo`        | 待辦增改勾刪（`action`=`add`/`update`/`done`/`undone`/`remove`/`clear_done`，可帶 `due`/`priority`/`repeat`）          |
| `reminder`    | 提醒增改刪/推遲（`at` / `daily_at` / `weekly_at`+`weekdays` / `monthly_at`+`day_of_month` / `every_minutes` / `cron`） |

對著對話說「記一下今天會上定的三件事」「提醒我週五 18:00 交週報」「我還有什麼沒做的」，
agent 就會自己調這個工具；不想要就去設定裡把它關掉（與其它外掛工具同一套開關）。

## 資料與邊界

- 資料落在 **`<dataDir>/notes/store.json`**（預設 `~/.pi-web/notes/store.json`），原子寫；
  匯入前會留一份 `store.json.bak`。**刪外掛不刪資料**，重灌即接著用。
- 提醒按**伺服器本地時區**觸發（不是瀏覽器的時區）：服務端到點把提醒放進「待送達佇列」，
  瀏覽器連著就立刻收到並彈提示；**瀏覽器沒開**時留著，下次開啟補送一次（補送過的不會重複彈，
  同瀏覽器去重記在 localStorage）。介面上「下次 …」顯示的時刻按**瀏覽器時區**格式化（它是同一個
  絕對時刻，只是換了個時區寫法）。
- 定時只有**一條**：每分鐘巡檢一次庫（`host.schedule("* * * * *")`，宣告持久、重啟自動重建），
  每條提醒自己帶一個「該響的時刻」（`nextDue`，隨庫落盤）。這樣做有兩個原因：① 一次性提醒用
  cron 表達時，錯過的時刻會被順延到明年；② 宿主用 `setTimeout(next - now)` 引爆，延遲超過
  Node 的 24.8 天上限會溢位（詳見下面「已知的宿主限制」）。附帶好處：停機期間錯過的那一次會在
  下次啟動時補上；2 分鐘內要響的還會再排一個精確定時，避免最多晚一分鐘。
- 庫檔案解析失敗（手改壞/半截寫）時會先隔離成 `store.json.corrupt-<時間戳>` 再以空庫啟動，
  **絕不靜默覆蓋**；匯入前也會留一份 `store.json.bak`。
- 「每隔 N 分鐘」是**真間隔**（1 分鐘 .. 7 天，任意整數）：到點判定用我們自己的 `nextDue`，
  不依賴 cron 表達能力，所以 90 分鐘這種也照常走；相位接著上一次到點時刻算，不會因為巡檢的
  分鐘對齊而慢慢漂。
- **映象只單向匯出**：真相永遠是外掛自己的 `store.json`，改映象檔案不會迴流；清理只刪我們
  自己在 `<映象目錄>/.pi-notes-mirror.json` 索引裡記過的檔案，絕不碰你目錄裡的其它東西。
- **與內建定時任務的分工**（容易混，特此寫清）：
  - 本外掛的提醒 = **提醒你這個人**（彈通知/桌面通知/提示音，跟待辦/議程/浮窗在一起）。
  - `host` 內建的「定時任務」（issue #184，頂欄後臺任務面板 / `schedule` 工具）=
    **到點讓 AI 跑一段指令**（無頭執行或喚醒原對話，有執行歷史）。
  - 所以：想讓 AI 到點幹活，請直接說「每天 9 點提醒我寫日報」讓 agent 用 `schedule`（action=create）；
    別在外掛裡建一條提醒再指望它去執行 —— 那會變成兩套「AI 待會兒會做什麼」，兩邊都難查。
- 許可權宣告：`ui`（頂欄條目 + 通知條）、`http`（外掛自己的 `/plugins-api/notes/*` 通道）、
  `tools`（AI 工具）、`fs`（Markdown 映象寫目錄，僅在你開啟映象且授權該目錄後才會用到）、
  `dom:anchor`（把浮窗掛進宿主錨點範圍，**不需要**使用者單獨授權 DOM）。
- 站內通知條 / 桌面通知 / 提示音 / 提醒時自動展開浮窗，四個開關在浮窗 ⚙ 裡（存瀏覽器
  localStorage）——這幾項是「這臺裝置上的這個瀏覽器」的偏好，故意不跟著庫走。

## 已知的宿主限制（與外掛的關係）

`host.schedule` 的 cron 用 `setTimeout(next - now)` 引爆，而 Node 的 setTimeout 延遲超過
2^31-1 ms（≈24.8 天）會**溢位成 1ms**；宿主的 `nextCronFire` 在「一年內找不到」時又會回一個
366 天后的哨兵值。兩者相遇就是「1ms 後再觸發 → 再排下一次」的死迴圈（本機實測復現：
`TimeoutOverflowWarning` + 每秒上千次觸發 + 每次同步寫盤）。

本外掛因此**不把遠期 cron 交給宿主**：只用一條每分鐘的巡檢（一定在安全視窗內），遠期提醒靠
自己的 `nextDue` 判定。用 `host.schedule` 的其它外掛如果傳「下次 > 24.8 天」的表示式會踩到這個
坑，修法在宿主側（`server/plugins.ts` 的 `armCron` 對超長延遲分片，`nextCronFire` 該回 null
而不是哨兵值）。

## 排障

- **頂欄找不到 📓 筆記**：外掛沒裝或啟用失敗 → 設定 →「介面外掛」看它是否帶錯誤資訊；
  被隱藏了 → 設定 →「介面佈局」裡恢復（頂欄條目和別的入口同一套規則）。
- **收不到提醒**：① 提醒列表裡那條是不是「已停用」；② 服務端在不在（浮窗底部的小圓點：
  綠=線上、紅=離線）；③ 桌面通知預設要瀏覽器授權，被拒過要去位址列許可權裡改回來。
- **提醒時間不對**：按伺服器本地時區算，不是瀏覽器時區（`date` 看一下伺服器的時區）。
- **浮窗拖沒了**：浮窗 ⚙ →「重置浮窗位置」。
- **想看日誌**：設定 →「介面外掛」→ 該外掛的「日誌」（`host.log` 的記憶體環形緩衝）。

## 開發與迴歸

```bash
npm run build:server && node tests/notes-test.mjs      # 協議 E2E：清單/HTTP/長輪詢/持久化
npm run build && node tests/notes-ui-test.mjs          # 瀏覽器 E2E：浮窗/拖拽/快速捕獲/提醒到點
npx vitest run tests/unit/notes-plugin.test.ts         # 純函式 + 假宿主（29 例：排程/間隔/映象/匯入…）
```

目錄結構：

```
plugins/notes/
├── manifest.json          # 能力宣告 + 頂欄條目（notes:toggle）
├── index.mjs              # 服務端：落庫 / 持久定時 / HTTP 路由 / AI 工具 / 斜槓命令
└── client/                # 只有這個子樹會下發給瀏覽器（見 server/index.ts 的靜態對映）
    ├── entry.mjs          # 客戶端入口（view:false + preload:true：頂層程式碼直接建浮窗，沒有 mount）
    ├── store.mjs          # 資料模型與全部純邏輯（服務端也 import 這一份）
    ├── cron.mjs           # 5 欄位 cron 解析與「下次觸發」計算（兩端共用）
    ├── data.mjs           # HTTP + 長輪詢資料客戶端（檢視與浮窗共用）
    ├── app.mjs            # 介面本體（緊湊浮窗佈局）
    ├── panel.mjs          # 可拖拽浮窗外殼（位置/尺寸/最小化）
    ├── settings-form.mjs  # 設定表單（通知開關/語言/匯入匯出，覆蓋層用）
    ├── dom.mjs            # 極簡 DOM 建構子（el，四個模組共用）
    ├── prefs.mjs          # 瀏覽器本地偏好（通知/提示音/語言）
    ├── i18n.mjs           # 中英文案
    └── styles.mjs         # 樣式（走宿主主題變數，自動跟隨深淺色主題）
```
