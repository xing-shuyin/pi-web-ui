# live-preview（即時預覽）

Live Server 式預覽外掛，無獨立檢視 tab——在右欄檔案樹上點右鍵用：

- 🌐 **Live Server 開啟**：右鍵資料夾 → 開啟該目錄；右鍵檔案 / 列表空白處 → 開啟當前目錄；點選直接新標籤開啟 `/liveserver/...`（相對路徑的 css/js/圖片可用，改檔案自動重新整理）。
- 📝 **預覽 Markdown**（僅檔案行顯示）：`.md` 檔案走 `/md/...` 渲染，其它檔案回落到 Live Server；點選直接新標籤開啟。
- 🧭 **標題導航**（`/md` 頁）：左側一列目錄，滾動高亮、點選跳轉、拖動改寬、`Ctrl/Cmd+\` 摺疊；開關與寬度記在瀏覽器本地。標題不足 2 個、或正文自帶標題 id 時不注入。

真服務只綁 `127.0.0.1:隨機口`（外部直連不可達也無妨），經宿主**通用代理**
（`host.registerProxy`）對外只露 `/liveserver` 與 `/md` 兩個同源字首。

AI 可用 `live_preview` 工具（引數 `path` 可給檔案或目錄，預設根目錄）拿預覽地址；
預設瀏覽器自動新標籤開啟（工具引數 `open:false` 或本頁設定關閉可停；瀏覽器攔截彈窗時點結果裡的連結）。

## 說明

- 根目錄 = 當前工作區（`set_cwd` 切專案後重新整理即看新專案），越界路徑一律拒絕；
- 文本走宿主解碼（UTF-8 失敗回落 GBK），老中文頁面不亂碼；
- 預覽檔案上限 10MB；單段 `Range` 已實現（mp4 拖進度條可用）；
- 需要能力 `http`（註冊代理）+ `fs`（讀工作區）+ `tools`（`live_preview` 工具）+ `ui`（右鍵選單）；
- 設定裡可關自動重新整理；頂欄後臺任務面板可停掉內建服務（過載外掛恢復）。
