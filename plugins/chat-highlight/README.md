# 正文高亮（chat-highlight）

按内容给聊天正文上色：引号台词、角色行、旁白、邮件头、issue / SHA / 路径、链接与邮箱、日期、金额、`@提及`、斜杠命令，外加一条自定义正则。

**纯展示、零代码**：插件没有 `index.mjs`、没有 `client/entry.mjs`，只声明 `chatDecorations`，由宿主用 CSS Custom Highlight API 上色。不替换文本、不插 HTML、不改 DOM 结构——复制、搜索、导出图片、朗读读到的仍是原文。

## 安装

插件市场搜「正文高亮」，或装到 `<dataDir>/plugins/chat-highlight/` 后重新扫描。声明能力只有 `decorate`（不需要 `dom` 授权、不需要联网、不读写文件）。

## 分组

全部在 设置 → 界面插件 → 正文高亮 里逐项开关；关掉的分组连正则都不编译。

| 分组 | 命中什么 | 默认 |
| --- | --- | --- |
| 对话引号 | `„…“`、`“…”`、`«…»`、`»…«`、`"…"`（跳过代码块） | 开 |
| 角色台词行 | 行首「名字：」→ 加粗 + 主色 | 开 |
| 括号旁白 | 全角括号 `（…）` → 弱色 | 开 |
| 邮件 / 信封头 | `From:`、`Subject:`、`发件人：`、`主题：` 等 → 加粗 + 链接色 | 开 |
| 技术标识 | `#123`、7 位以上 SHA、`src/…` `web/…` 路径（可带 `:行号`） | 开 |
| 链接与邮箱 | `http(s)://…`、`a@b.c` | 开 |
| 日期与时间 | `2026-11-22`、`2026年11月22日`、`14:05` | 开 |
| 金额 | `¥1,299.00`、`$99`、`99 元` / `USD` | 开 |
| @ 提及 | 行内 `@someone`（邮箱优先，不会被拆开） | 关 |
| 斜杠命令 | **只作用于我的消息**：`/compact`、`/new` | 开 |
| 自定义规则 | 下面的「自定义正则」，留空不生效 | 关 |

## 颜色

五个文本框，写任意 CSS 颜色；默认值都是**主题令牌**，换主题自动跟着变：

| 设置 | 默认 | 作用 |
| --- | --- | --- |
| 主色 | `var(--accent)` | 台词、角色行、命令、自定义规则（未单独设色时） |
| 弱色 | `var(--text-dim)` | 旁白、日期时间 |
| 链接色 | `var(--blue, var(--accent))` | 链接、邮箱、技术标识、邮件头、@提及 |
| 金额色 | `var(--amber, var(--accent))` | 金额 |
| 自定义色 | `var(--accent)` | 只作用于自定义规则 |

想复刻「对话橙色」：把主色改成 `#e8832a` 即可。

## 自定义正则

「自定义正则」接受 JavaScript 正则**源**（不带 `/…/`），例如：

```
订单号[:：]\s*\w+          # 订单号：A1234
(?:TODO|FIXME)\([^)]*\)    # TODO(owner)
```

- 最长 200 字符，flags 固定 `gmu`（强制 `g`）；
- 每块最多 200 处命中，超出截断；
- 正则非法只会让这一条失效，其它分组照常，控制台会打印原因；
- 只上色，不改变任何文本。

## 边界（做不到的事）

- 不能替换/隐藏/重排文本，不能改字体族、字号、斜体（宿主只开放 `color` / `backgroundColor` / `fontWeight`）；
- 不作用于代码块（`pre` / `code`）、按钮、空状态文案，只作用于正文 markdown；
- 只作用于当前聊天正文（`[data-chat-transcript]`），插件页、笔记、终端里的 markdown 不受影响；
- 浏览器没有 CSS Custom Highlight API（Firefox < 140）时静默不生效，正文保持原样。

## 卸载

设置里禁用或删除目录即可，所有着色立即消失；没有落盘数据。
