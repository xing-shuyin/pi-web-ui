# Live2D 看板娘 (Live2D Companion) 外掛

基於 **Live2D Cubism 2 / 3 / 4** 與 **PixiJS** 的頁面級智慧體桌面陪伴看板娘，為 `pi-web-ui` 注入生動的互動生命力。

---

## 🌟 核心特性

- **多代 Live2D 模型全支援**：同時支援 Cubism 2（`.model.json`）與 Cubism 3/4（`.model3.json`），內建 4 套官方離線開源模型（🌸 雫 / 🌿 春 / ☀️ 日和 / 🐶 萌柴），零外網即可秒開！
- **自然視線與頭部跟蹤**：
  - **👀 滑鼠視線跟隨（Mouse Tracking）**：眼珠與頭部隨游標在螢幕上的移動自然偏轉；
  - **💤 自然呼吸待機（Natural Idle）**：輕柔呼吸起伏與隨機眨眼；
- **豐富的觸控與動作反饋**：
  - 單擊頭部：觸發摸頭動作，展露開心笑容與親切氣泡臺詞；
  - 單擊身體：害羞/驚訝微動反應；
  - 雙擊角色：觸發晃動並隨機送出溫馨問候與靈感提醒；
- **AI 對話情緒深度聯動**：
  - 智慧體思考 / 工具呼叫中：看板娘展露專注思考表情並冒出思考氣泡；
  - 智慧體完成回答：看板娘開心點頭與打招呼；
  - 智慧體遇到報錯：看板娘展露關切與吃驚表情；
- **完全自由的頁面懸浮控制元件**：
  - **自由拖拽**：滑鼠左鍵按住即可拖動到螢幕任意位置，自動記憶座標；
  - **滾輪縮放**：在掛件上滾動滑鼠滾輪即可隨心調整大小比例（0.4x ~ 2.0x）；
  - **快捷懸浮操作條**：滑鼠懸停在掛件側邊，平滑滑出表情切換、換裝、模式切換、設定與收起按鈕；
  - **右鍵上下文選單**：右鍵點選彈出完整控制選單；
  - **極簡掛起膠囊**：點選收起後在螢幕右下角留存可愛小貓爪（🐾），點選隨時喚回；
  - **全域性快捷鍵**：按下 `Alt+L` 或點選頂欄按鈕隨時切換顯隱。
- **點選穿透與透明放行**：
  - **✨ 智慧透明畫素穿透**：預設開啟！游標在人物周圍透明區域時，所有滑鼠點選、文字選中、滾輪滾動 100% 自然穿透到底層網頁，絕不阻擋操作；游標移至角色實體時自動啟用摸頭拖拽；
  - **👻 完全點選穿透模式 (Ghost 幽靈模式)**：在右鍵選單、懸浮快捷欄（👻）或設定面板中一鍵開啟，看板娘進入純觀賞模式，完全不攔截任何滑鼠互動，絲毫不阻礙打字與看文件；
- **本地模型一鍵上傳與管理**：
  - **📦 支援 ZIP 壓縮包上傳**：支援將下載好的 Live2D 模型 `.zip` 壓縮包一鍵拖入或選擇上傳，服務端自動解壓、智慧嗅探 `.model3.json` / `.model.json` 並即刻換裝；
  - **📂 支援本地模型資料夾上傳**：直接從電腦中選擇已解壓的模型目錄批次上傳；
  - **🗑️ 模型管理與清理**：在設定面板中可一鍵刪除已上傳的自定義模型，釋放磁碟空間。

## 🤖 AI 智慧體專屬操控工具

外掛向 pi 編碼智慧體註冊了統一操控工具 `live2d`，智慧體可在回覆使用者時主動與看板娘產生互動：

| 工具名稱 | 功能描述                                                       | 核心操作 (action)                                                                                                                                                    |
| :------- | :------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `live2d` | 統一看板娘操控工具：模型切換、表情、氣泡、音樂口型對齊、眨眼等 | `list_models`, `get_current_model`, `list_expressions`, `play_expression`, `show_bubble`, `switch_mode`, `switch_model`, `play_audio`, `stop_audio`, `trigger_blink` |

---

## 📡 HTTP API 介面

外掛通過 `/plugins-api/live2d/*` 暴露 HTTP 路由：

- `GET /models`：獲取全部已配置模型列表與當前狀態；
- `GET /current-model`：獲取當前展示的模型；
- `GET /expressions`：獲取模型表情列表；
- `POST /action`：觸發看板娘動作（相容 `live2d_pet` 協議）：
  - 播放表情：`{"action": "expression", "name": "happy"}`
  - 顯示氣泡：`{"action": "message", "text": "你好！", "duration": 4000}`
  - 切換模式：`{"action": "mode", "mode": "mouse"}`
  - 切換模型：`{"action": "model_switch", "model": "shizuku"}`
