# browser-use · 常駐 Chrome 自動化與智慧搜尋外掛

基於 [DrissionPage](https://www.drissionpage.cn) 的常駐 Chrome 自動化外掛，為 AI 註冊**單一**原生工具 `browser_use`：頁面互動與聯網搜尋（`action: "search"`）合一，省下一份工具定義與一次決策成本。

## 核心特性

- **高效真實瀏覽器搜尋（`browser_use(action: "search")`）**：
  - **獨立後臺標籤頁隔離（Tab Isolation）**：搜尋在後臺專用的 Worker 標籤頁上靜默執行，無論前臺當前在瀏覽文件、填表還是等待使用者操作，**絕不沖掉前臺活動頁面**；搜尋完畢前臺焦點完好保留。
  - **CDP 極速無圖渲染（Fast SERP）**：通過底層 CDP 阻斷圖片、影片、字型及第三方跟蹤指令碼的載入，頁面毫秒級就緒，端到端速度提升 50%~70%，大幅節省頻寬。
  - **時效性過濾與釋出時間提取**：支援 `timeRange` 引數（`day` 過去24小時、`week` 過去1周、`month` 過去1個月、`year` 過去1年），並自動從 SERP 卡片中提純絕對日期（如 `2024-03-15`）或相對時間（如 `3小時前`），徹底消除知識時效盲區。
  - **真實落地頁清洗還原（Clean URLs）**：深度解碼 Google、DuckDuckGo、Bing 等跟蹤跳轉層，深度解析百度 `mu`/`data-tools` 及搜狗 360 的真實落地頁，杜絕後續閱讀被 302 防盜鏈攔截。
  - **一步直達免往返**：直接構造搜尋引擎引數秒級提取結果，避免“開啟主頁→尋找輸入框→鍵入文字→回車→等待快照”等多輪往返，單次 Tool Call 即刻返回結果。
  - **廣告與雜質強力過濾**：內建各大搜索引擎 DOM 精準過濾器，自動剝離商業推廣、贊助商廣告、Cookie 彈窗與噪音側欄，僅保留真實的自然搜尋結果。
  - **相關搜尋詞建議（Related Queries）**：自動提取 SERP 底部的關聯推薦搜尋詞，拓展智慧體的發散檢索能力。
  - **多引擎無縫回退（Fallback）**：預設支援 `bing`（中英平衡、免翻無阻）、`google`（全球前沿）、`baidu`（中文本土）與 `duckduckgo`（無追蹤）等 8 大主流引擎；遭遇驗證碼或反爬阻斷時，自動平滑降級到備選引擎，保障搜尋可靠性。
  - **即時直達卡片解析**：針對天氣、匯率、程式碼片段、定義卡片等即時答案（Instant Answer / Featured Snippets）優先提取，無需翻閱落地頁即可直接命中答案。
  - **極省 Token 預算**：精煉提取標題、直鏈、精準摘要與釋出來源，整屏結果控制在 500~1000 tokens，不擠佔長上下文視窗。
- **零配置常駐瀏覽器**：無需手動修改 Chrome 啟動引數或除錯埠。外掛自動拉起或連線一個常駐實體 Chrome 視窗（預設埠 `9333`，使用獨立沙箱 profile，絕不與使用者日常 Chrome 衝突）。
- **後臺任務統一管理**：瀏覽器執行時自動註冊到 Web UI 的 **「後臺任務」** 面板（顯示當前埠、開啟標籤頁數量），支援在面板中一鍵點選 **[停止]** 隨時優雅關閉瀏覽器；與宿主的“自動清理遺留”及“全部關閉”完全打通。
- **閒置超時自動關閉**：長時間不使用自動退出並釋放系統記憶體與 CPU 資源（預設 15 分鐘無任何操作自動關閉；可在外掛設定中自由調整為 0~180 分鐘，設為 0 表示永不自動關閉）。
- **自然人機協同**：視窗在桌面上可見且在會話期間保持。使用者可以在該窗口裡隨手開啟標籤頁、手動掃碼登入（微信/淘寶/GitHub 等），AI 隨時呼叫 `tabs` 與 `switch` 無縫接管已開啟的頁面。
- **Token 極致節省**：獨有的 `snapshot -i` 頁面快照僅提取人類可見的互動元素（帶有 `[1] [button] 登入` 等序號），徹底剝離幾萬行冗餘 DOM 與 CSS/JS 內部實現。
- **全能互動能力**：支援點選、輸入、下拉選擇、核取方塊勾選、聚焦打字、組合鍵（`Enter`、`ctrl+a` 等）、平滑滾動、JS 表示式執行、整頁長截圖等。
- **原生反爬穿透**：繼承 DrissionPage 對 Chromium 底層 CDP 的最佳化，具有極高的擬人化特徵，不易被風控與驗證碼阻斷。

## 安裝與依賴

1. **啟用外掛**：在 pi-web-ui 設定 → 外掛管理中開啟 `browser-use`。
2. **環境要求**：系統需安裝 Python 3（以及安裝了 Chrome 或 Chromium）。
   - 首次使用時，外掛指令碼會自動在外掛目錄下建立 `.venv` 並通過 pip 安裝 `drissionpage`（約需 20~30 秒，自動就緒）。
   - 若系統已存在帶 `drissionpage` 的環境，會自動優先複用。

## 外掛設定

在 pi-web-ui 設定 → 外掛管理 → `browser-use` 齒輪圖示中可配置：

- **無頭模式 (Headless)**（`headless`）：
  - 預設值：`true`（已預設開啟）
  - 說明：開啟後常駐 Chrome 在後臺靜默執行，絕不彈出實體桌面視窗打擾工作；如需人工觀察瀏覽器或手動掃碼登入特定網站，可臨時在設定中關閉該選項。
- **閒置自動關閉（分鐘）**（`idleTimeoutMinutes`）：
  - 預設值：`15` 分鐘
  - 範圍：`0` ~ `180` 分鐘
  - 說明：當 AI 或使用者在設定的時長內沒有對常駐瀏覽器執行任何操作時，後臺自動觸發平穩退出以完全釋放記憶體；設定為 `0` 表示保持常駐、永不自動關閉。
- **預設搜尋引擎**（`defaultEngine`）：
  - 預設值：`"auto"`（智慧自適應降級）
  - 可選項：`auto`、`bing`、`baidu`、`sogou`、`so`、`google`、`duckduckgo`、`brave`、`yahoo`
  - 說明：未顯式指定搜尋引擎時的預設首選項；遇驗證碼或反爬會自動按降級鏈重試。
- **極速搜尋模式**（`fastSearch`）：
  - 預設值：`true`
  - 說明：搜尋時通過底層 CDP 阻斷圖片、字型與媒體資源下載，頁面毫秒級解析，大幅節省寬頻與耗時。
- **搜尋標籤頁隔離**（`searchTabIsolation`）：
  - 預設值：`true`
  - 說明：在後臺專用標籤頁執行搜尋，不打擾或覆蓋您當前前臺正在瀏覽互動的網頁。

## 後臺任務精確管理

瀏覽器執行時自動登記到 Web UI 右上角或狀態列的 **「後臺任務」** 面板：

- **即時狀態感知**：即時顯示當前執行埠（`9333`）、開啟的標籤頁數量以及無頭模式狀態；
- **一鍵精準停止**：在後臺任務列表中點選 **[停止]** 按鈕，系統會先發送平穩優雅退出訊號，並配合埠級強力釋放兜底，確保在 1~2 秒內徹底關閉 Chrome 程序並完全釋放埠，絕不殘留殭屍程序；
- **與宿主生命週期打通**：支援 Web UI 的“全部關閉”與“自動清理遺留任務”機制，隨應用優雅啟停。

## 搜尋能力：`browser_use(action: "search")`

搜尋不單獨註冊工具，統一由 `browser_use` 的 `search` 動作承載；需要聯網搜尋最新資訊、排查報錯、查詢官方文件時首選該動作（關鍵詞誤傳進 `text` 也會被自動兜底識別）：

| 引數 `param`      | 型別      | 必填 | 說明                                                                                                                                                                |
| :---------------- | :-------- | :--- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `query`           | `string`  | 是   | 搜尋關鍵詞，支援引擎高階語法（如 `site:github.com`、`"exact phrase"` 等）                                                                                           |
| `engine`          | `string`  | 否   | 搜尋引擎：`"auto"`（預設智慧優選）、`"bing"`（微軟必應）、`"sogou"`（搜狗）、`"so"`（360搜尋）、`"baidu"`（百度）、`"google"`、`"duckduckgo"`、`"brave"`、`"yahoo"` |
| `timeRange`       | `string`  | 否   | **時效性過濾**：`"day"`（過去24小時）、`"week"`（過去1周）、`"month"`（過去1個月）、`"year"`（過去1年）、`"all"`（預設全部）                                        |
| `page`            | `number`  | 否   | **搜尋翻頁頁碼**：預設 `1`（第 1 頁），傳入 `2`、`3` 等可按各引擎原生分頁偏移量精準翻頁檢索深層結果                                                                 |
| `fetchTopContent` | `boolean` | 否   | **搜閱一體模式**：在搜尋的同時自動在後臺提取排名第一的權威自然結果核心純淨正文（1500~2000 字元），一次 Tool Call 即刻搞定“搜+閱”（預設 `false`）                    |
| `limit`           | `number`  | 否   | 返回的最大自然搜尋結果數量（1~20，預設 `8` 條）                                                                                                                     |
| `officialOnly`    | `boolean` | 否   | **官網與權威站點過濾**：優先/僅保留官方認證站點與權威開源文件（預設 `false`）                                                                                       |

### 如何讓搜尋精準搜到官網與權威站點（徹底杜絕廣告）

在面對充斥著山寨下載站、代理商推廣與營銷洗稿站的網路環境時，`browser_use(action: "search")` 從三個維度確保官網與權威站點精準優先：

1. **自動識別官方認證徽章（Official Badges）**：
   - 內建針對各大搜索引擎官方認證標記的 DOM 識別器（如百度 `.c-icon-v` 官方認證、360 `.icon-official` 官網盾牌、搜狗 `.vr-official` 標籤、Google/Bing 官方知識卡片）；
   - 只要被搜尋引擎認證為真正官網，系統自動打上 `🏷️ [官網/權威]` 顯著標識並**強制置頂排在第 1 位**。
2. **權威頂級域名加權（Authority Domain Boost）**：
   - 針對官方程式碼庫（`github.com`, `apache.org` 等）、權威組織（`*.gov`, `*.edu`, `*.org`）、官方技術文件（`developer.mozilla.org`, `readthedocs.io` 等）及官方包託管平臺（`npmjs.com`, `pypi.org`, `crates.io`），自動判定為高權威站點優先推薦。
3. **全引擎廣告物理粉碎**：
   - 在瀏覽器 V8 上下文直接剔除包含 `.b_ad`, `.ec_wise_ad`, `.e-prom`, `.sponsor`, `#taw`, `[data-text-ad]` 等廣告特徵的 DOM 樹，杜絕商業推廣混入模型視野。
4. **指定 `officialOnly: true`**：
   - 若只需要官網連結（例如排查某個開源專案的真實主頁或下載官方安裝包），開啟此引數即可自動過濾所有非官方部落格或二次分發站。

### 搜尋引擎適配矩陣與優選策略

| 搜尋引擎程式碼 `engine` | 引擎名稱       | 適用場景與優勢                                                                               | 廣告過濾與落地頁還原策略                                |
| :---------------------- | :------------- | :------------------------------------------------------------------------------------------- | :------------------------------------------------------ |
| **`auto`**（預設推薦）  | 全自動智慧優選 | 優先嚐試必應與國內免梯高速引擎，若遇阻斷或驗證碼，**毫秒級自適應無縫輪轉**，保證 100% 成功率 | 繼承所有引擎的最佳清洗規則                              |
| **`bing`**              | 微軟必應       | 國內免翻無阻、中英文質量俱佳、支援即時答案與程式碼卡片                                       | 強力剝離 `.b_ad` 競價推廣與側欄噪音                     |
| **`sogou`**             | 搜狗搜尋       | 國內第二大中文引擎，知乎/微信生態資源豐富，**極低風控、幾乎零驗證碼**                        | 剔除 `.sponsor` 推廣，提取真實落地頁                    |
| **`so`** / **`360`**    | 360 搜尋       | 國內主流安全搜尋引擎，速度極快，防爬寬鬆穩定                                                 | 過濾 `.e-prom` 商業推廣，還原 `data-url`                |
| **`baidu`**             | 百度搜索       | 本土資訊、生活百科與社群最豐富                                                               | 深度過濾百家號推廣，解析 `mu`/`data-tools` 還原真實 URL |
| **`google`**            | 谷歌搜尋       | 全球最前沿權威技術與外文資料                                                                 | 過濾 Google 贊助商卡片與內鏈跳轉                        |
| **`duckduckgo`**        | DuckDuckGo     | 極客與隱私搜尋，零追蹤                                                                       | 解密 `uddg` 還原乾淨落地頁                              |
| **`brave`**             | Brave Search   | 全球獨立新一代隱私引擎，不依賴 Google/Bing 索引                                              | 提取獨立卡片並過濾側欄浮窗                              |
| **`yahoo`**             | 雅虎搜尋       | 經典全球多語言通用搜索                                                                       | 提取自然結果與摘要                                      |

> **通用自適應兜底引擎（Universal Fallback）**：針對市面任意搜尋引擎，即使頁面樣式發生改版，內建的自適應啟發式演算法依然能在頁面主體中自動識別高質量標題+摘要卡片。

### 零結果必須說清「被攔」還是「真沒有」

搜尋零結果是最容易被誤讀的場景：**「未找到結果」不等於關鍵詞搜不到**，很可能是反爬驗證碼或網路不可達。因此 `browser_use(action: "search")` 在零結果時不再輸出統一話術，而是逐引擎交代真實原因：

```
⚠️ 沒有拿到任何結果，但這不等於「搜不到」——各引擎實際回報：
    · baidu — 人機驗證/反爬攔截：百度安全驗證（頁面被重定向到驗證頁 https://wappass.baidu.com/...）
    · sogou — 人機驗證/反爬攔截：搜狗反爬攔截
    · google — 網路不可達：瀏覽器網路錯誤（ERR_CONNECTION_TIMED_OUT）
診斷：2 個引擎被人機驗證/反爬攔截，1 個網路不可達。
```

配套的三條硬機制：

1. **攔截識別覆蓋真實驗證頁**：URL 特徵（`wappass.baidu.com`、`/antispider/`、`qcaptcha.so.com`、`google.com/sorry`）優先於正文關鍵詞，另加 Chrome 錯誤頁（`ERR_CONNECTION_TIMED_OUT` / 無法訪問此網站）與驗證碼控制元件探測；引擎自述「沒有找到相關結果」時才歸為**真的沒結果**。
2. **搜尋引擎健康自檢（帶快取）**：對每個引擎域名做 TCP 可達性探測，並記住近期被攔截的引擎。非首選引擎若確認不可達/剛被攔，直接跳過並在原因中標註，不再為四個境外引擎各白等一次 6 秒超時（一次搜尋可省 20~40 秒）。
3. **搜尋互斥，杜絕併發串味**：所有搜尋共用一個 `window.name` 標記的後臺 worker 標籤頁（跨導航存活，不再每次新開標籤頁導致洩漏），並由程序內佇列 + 跨程序檔案鎖序列化——併發搜尋不會互相踩頁面導致結果串味或誤報「無結果」。

相關環境變數：

| 變數                     | 預設  | 作用                                             |
| :----------------------- | :---- | :----------------------------------------------- |
| `DP_ENGINE_HEALTH_TTL`   | `600` | 引擎可達性探測快取秒數（0 = 每次都探）           |
| `DP_ENGINE_BLOCK_TTL`    | `900` | 被攔截引擎的冷卻秒數（冷卻期內非首選時直接跳過） |
| `DP_SEARCH_LOCK_TIMEOUT` | `90`  | 搜尋檔案鎖最長等待秒數（超時放棄加鎖，避免卡死） |
| `DP_SEARCH_LOCK_STALE`   | `120` | 超過該秒數的鎖視為殘留鎖並被清理                 |

呼叫示例：

```json
{
	"query": "DrissionPage CDP 常見報錯解決 site:github.com",
	"engine": "bing",
	"limit": 5
}
```

## 互動工具：`browser_use`

AI 可以直接使用原生 tool call 控制常駐瀏覽器（含搜尋）：

| 動作 `action`       | 關鍵引數                                                                                            | 說明                                                                                                                    |
| :------------------ | :-------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------------- |
| `search`            | `query`(或 `text`), `engine?`, `timeRange?`, `page?`, `fetchTopContent?`, `limit?`, `officialOnly?` | 執行真實瀏覽器搜尋並直接提取自然搜尋結果（原 `browser_search` 能力全部併入此動作）                                      |
| `read_page`         | `url?`, `maxChars?`                                                                                 | 閱讀器模式提取網頁純淨正文與核心程式碼塊，過濾所有噪音與廣告；支援 HTML 表格轉 Markdown、程式碼塊語法高亮（極省 Token） |
| `open`              | `url`                                                                                               | 在當前標籤頁開啟網址（自動補齊 `https://`）                                                                             |
| `new`               | `url`                                                                                               | 新建標籤頁並開啟網址                                                                                                    |
| `tabs`              | -                                                                                                   | 列出所有標籤頁（含序號、標題、網址及當前啟用狀態）                                                                      |
| `switch`            | `target`                                                                                            | 按序號（如 `"2"`）、標題或網址片段切換標籤頁                                                                            |
| `close`             | `target?`                                                                                           | 關閉標籤頁（預設當前啟用頁）                                                                                            |
| `snapshot`          | `interactiveOnly?`                                                                                  | 獲取頁面結構快照；`interactiveOnly: true` 時僅返回帶序號的互動元素                                                      |
| `click`             | `target`, `byJs?`                                                                                   | 點選元素（可傳快照序號 `"3"`、文本 `"Sign in"` 或 CSS 選擇器）                                                          |
| `input`             | `target`, `text`                                                                                    | 清空並輸入文本                                                                                                          |
| `select`            | `target`, `option`                                                                                  | 下拉框選擇（按選項文本、值或序號）                                                                                      |
| `check` / `uncheck` | `target`                                                                                            | 勾選 / 取消勾選核取方塊或單選框                                                                                         |
| `type`              | `text`                                                                                              | 向當前獲得焦點的元素直接打字                                                                                            |
| `press`             | `key`                                                                                               | 觸發按鍵或快捷鍵（如 `"Enter"`、`"ctrl+a"`、`"Escape"`）                                                                |
| `hover`             | `target`                                                                                            | 滑鼠懸停在指定元素上                                                                                                    |
| `scroll`            | `scroll`                                                                                            | 頁面滾動：`"top"`、`"bottom"`、`"up"`、`"down"` 或畫素值                                                                |
| `wait`              | `seconds`                                                                                           | 等待指定秒數                                                                                                            |
| `js` / `jsx`        | `code`                                                                                              | 執行 JavaScript 程式碼或獲取表示式值                                                                                    |
| `console`           | `level?`, `clear?`, `limit?`, `query?`                                                              | 檢視當前標籤頁控制台日誌（自動捕獲 `log`/`warn`/`error` 與未捕獲異常，支援按級別過濾與清空）                            |
| `screenshot`        | `path?`, `fullPage?`                                                                                | 擷取頁面截圖（支援 fullPage 長圖）                                                                                      |
| `quit`              | -                                                                                                   | 關閉常駐瀏覽器視窗，結束當前自動化會話                                                                                  |

## 典型對話示例

- _“幫我查一下 Python 3.13 去除 GIL 的官方 PEP 進展”_  
  → AI 呼叫 `browser_use(action: "search", query: "Python 3.13 free threaded GIL PEP")`  
  → 2 秒內直接返回精簡無廣告的自然結果列表與官方連結。

- _“幫我去 GitHub 搜尋熱門的 DrissionPage 庫並檢視正文詳情”_  
  → AI 呼叫 `browser_use(action: "search", query: "DrissionPage github repo", limit: 3)` 獲取候選 URL  
  → AI 呼叫 `browser_use(action: "read_page", url: "https://github.com/g1879/DrissionPage")` 極速提取乾淨 README 正文（零垃圾程式碼與廣告，僅消耗約 1,500 tokens）。

- _“看看剛才開啟的頁面為什麼報錯，控制台輸出了什麼”_  
  → AI 呼叫 `browser_use(action: "console", level: "error")`  
  → 立即獲取當前網頁捕獲到的所有未捕獲異常（Uncaught Exception）、Promise Rejection 與 `console.error` 輸出及檔案堆疊。
