# browser-use · 常驻 Chrome 自动化与智能搜索插件

基于 [DrissionPage](https://www.drissionpage.cn) 的常驻 Chrome 自动化插件，为 AI 注册**单一**原生工具 `browser_use`：页面交互与联网搜索（`action: "search"`）合一，省下一份工具定义与一次决策成本。

## 核心特性

- **高效真实浏览器搜索（`browser_use(action: "search")`）**：
  - **独立后台标签页隔离（Tab Isolation）**：搜索在后台专用的 Worker 标签页上静默执行，无论前台当前在浏览文档、填表还是等待用户操作，**绝不冲掉前台活动页面**；搜索完毕前台焦点完好保留。
  - **CDP 极速无图渲染（Fast SERP）**：通过底层 CDP 阻断图片、视频、字体及第三方跟踪脚本的加载，页面毫秒级就绪，端到端速度提升 50%~70%，大幅节省带宽。
  - **时效性过滤与发布时间提取**：支持 `timeRange` 参数（`day` 过去24小时、`week` 过去1周、`month` 过去1个月、`year` 过去1年），并自动从 SERP 卡片中提纯绝对日期（如 `2024-03-15`）或相对时间（如 `3小时前`），彻底消除知识时效盲区。
  - **真实落地页清洗还原（Clean URLs）**：深度解码 Google、DuckDuckGo、Bing 等跟踪跳转层，深度解析百度 `mu`/`data-tools` 及搜狗 360 的真实落地页，杜绝后续阅读被 302 防盗链拦截。
  - **一步直达免往返**：直接构造搜索引擎参数秒级提取结果，避免“打开主页→寻找输入框→键入文字→回车→等待快照”等多轮往返，单次 Tool Call 即刻返回结果。
  - **广告与杂质强力过滤**：内置各大搜索引擎 DOM 精准过滤器，自动剥离商业推广、赞助商广告、Cookie 弹窗与噪音侧栏，仅保留真实的自然搜索结果。
  - **相关搜索词建议（Related Queries）**：自动提取 SERP 底部的关联推荐搜索词，拓展智能体的发散检索能力。
  - **多引擎无缝回退（Fallback）**：默认支持 `bing`（中英平衡、免翻无阻）、`google`（全球前沿）、`baidu`（中文本土）与 `duckduckgo`（无追踪）等 8 大主流引擎；遭遇验证码或反爬阻断时，自动平滑降级到备选引擎，保障搜索可靠性。
  - **即时直达卡片解析**：针对天气、汇率、代码片段、定义卡片等即时答案（Instant Answer / Featured Snippets）优先提取，无需翻阅落地页即可直接命中答案。
  - **极省 Token 预算**：精炼提取标题、直链、精准摘要与发布来源，整屏结果控制在 500~1000 tokens，不挤占长上下文窗口。
- **零配置常驻浏览器**：无需手动修改 Chrome 启动参数或调试端口。插件自动拉起或连接一个常驻实体 Chrome 窗口（默认端口 `9333`，使用独立沙箱 profile，绝不与用户日常 Chrome 冲突）。
- **后台任务统一管理**：浏览器运行时自动注册到 Web UI 的 **「后台任务」** 面板（显示当前端口、打开标签页数量），支持在面板中一键点击 **[停止]** 随时优雅关闭浏览器；与宿主的“自动清理遗留”及“全部关闭”完全打通。
- **闲置超时自动关闭**：长时间不使用自动退出并释放系统内存与 CPU 资源（默认 15 分钟无任何操作自动关闭；可在插件设置中自由调整为 0~180 分钟，设为 0 表示永不自动关闭）。
- **自然人机协同**：窗口在桌面上可见且在会话期间保持。用户可以在该窗口里随手打开标签页、手动扫码登录（微信/淘宝/GitHub 等），AI 随时调用 `tabs` 与 `switch` 无缝接管已打开的页面。
- **Token 极致节省**：独有的 `snapshot -i` 页面快照仅提取人类可见的交互元素（带有 `[1] [button] 登录` 等序号），彻底剥离几万行冗余 DOM 与 CSS/JS 内部实现。
- **全能交互能力**：支持点击、输入、下拉选择、复选框勾选、聚焦打字、组合键（`Enter`、`ctrl+a` 等）、平滑滚动、JS 表达式执行、整页长截图等。
- **原生反爬穿透**：继承 DrissionPage 对 Chromium 底层 CDP 的优化，具有极高的拟人化特征，不易被风控与验证码阻断。

## 安装与依赖

1. **启用插件**：在 pi-web-ui 设置 → 插件管理中开启 `browser-use`。
2. **环境要求**：系统需安装 Python 3（以及安装了 Chrome 或 Chromium）。
   - 首次使用时，插件脚本会自动在插件目录下创建 `.venv` 并通过 pip 安装 `drissionpage`（约需 20~30 秒，自动就绪）。
   - 若系统已存在带 `drissionpage` 的环境，会自动优先复用。

## 插件设置

在 pi-web-ui 设置 → 插件管理 → `browser-use` 齿轮图标中可配置：

- **无头模式 (Headless)**（`headless`）：
  - 默认值：`true`（已默认开启）
  - 说明：开启后常驻 Chrome 在后台静默运行，绝不弹出实体桌面窗口打扰工作；如需人工观察浏览器或手动扫码登录特定网站，可临时在设置中关闭该选项。
- **闲置自动关闭（分钟）**（`idleTimeoutMinutes`）：
  - 默认值：`15` 分钟
  - 范围：`0` ~ `180` 分钟
  - 说明：当 AI 或用户在设定的时长内没有对常驻浏览器执行任何操作时，后台自动触发平稳退出以完全释放内存；设置为 `0` 表示保持常驻、永不自动关闭。
- **默认搜索引擎**（`defaultEngine`）：
  - 默认值：`"auto"`（智能自适应降级）
  - 可选项：`auto`、`bing`、`baidu`、`sogou`、`so`、`google`、`duckduckgo`、`brave`、`yahoo`
  - 说明：未显式指定搜索引擎时的默认首选项；遇验证码或反爬会自动按降级链重试。
- **极速搜索模式**（`fastSearch`）：
  - 默认值：`true`
  - 说明：搜索时通过底层 CDP 阻断图片、字体与媒体资源下载，页面毫秒级解析，大幅节省宽带与耗时。
- **搜索标签页隔离**（`searchTabIsolation`）：
  - 默认值：`true`
  - 说明：在后台专用标签页执行搜索，不打扰或覆盖您当前前台正在浏览交互的网页。

## 后台任务精确管理

浏览器运行时自动登记到 Web UI 右上角或状态栏的 **「后台任务」** 面板：

- **实时状态感知**：实时显示当前运行端口（`9333`）、打开的标签页数量以及无头模式状态；
- **一键精准停止**：在后台任务列表中点击 **[停止]** 按钮，系统会先发送平稳优雅退出信号，并配合端口级强力释放兜底，确保在 1~2 秒内彻底关闭 Chrome 进程并完全释放端口，绝不残留僵尸进程；
- **与宿主生命周期打通**：支持 Web UI 的“全部关闭”与“自动清理遗留任务”机制，随应用优雅启停。

## 搜索能力：`browser_use(action: "search")`

搜索不单独注册工具，统一由 `browser_use` 的 `search` 动作承载；需要联网搜索最新资讯、排查报错、查找官方文档时首选该动作（关键词误传进 `text` 也会被自动兜底识别）：

| 参数 `param`      | 类型      | 必填 | 说明                                                                                                                                                                |
| :---------------- | :-------- | :--- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `query`           | `string`  | 是   | 搜索关键词，支持引擎高级语法（如 `site:github.com`、`"exact phrase"` 等）                                                                                           |
| `engine`          | `string`  | 否   | 搜索引擎：`"auto"`（默认智能优选）、`"bing"`（微软必应）、`"sogou"`（搜狗）、`"so"`（360搜索）、`"baidu"`（百度）、`"google"`、`"duckduckgo"`、`"brave"`、`"yahoo"` |
| `timeRange`       | `string`  | 否   | **时效性过滤**：`"day"`（过去24小时）、`"week"`（过去1周）、`"month"`（过去1个月）、`"year"`（过去1年）、`"all"`（默认全部）                                        |
| `page`            | `number`  | 否   | **搜索翻页页码**：默认 `1`（第 1 页），传入 `2`、`3` 等可按各引擎原生分页偏移量精准翻页检索深层结果                                                                 |
| `fetchTopContent` | `boolean` | 否   | **搜阅一体模式**：在搜索的同时自动在后台提取排名第一的权威自然结果核心纯净正文（1500~2000 字符），一次 Tool Call 即刻搞定“搜+阅”（默认 `false`）                    |
| `limit`           | `number`  | 否   | 返回的最大自然搜索结果数量（1~20，默认 `8` 条）                                                                                                                     |
| `officialOnly`    | `boolean` | 否   | **官网与权威站点过滤**：优先/仅保留官方认证站点与权威开源文档（默认 `false`）                                                                                       |

### 如何让搜索精准搜到官网与权威站点（彻底杜绝广告）

在面对充斥着山寨下载站、代理商推广与营销洗稿站的网络环境时，`browser_use(action: "search")` 从三个维度确保官网与权威站点精准优先：

1. **自动识别官方认证徽章（Official Badges）**：
   - 内置针对各大搜索引擎官方认证标记的 DOM 识别器（如百度 `.c-icon-v` 官方认证、360 `.icon-official` 官网盾牌、搜狗 `.vr-official` 标签、Google/Bing 官方知识卡片）；
   - 只要被搜索引擎认证为真正官网，系统自动打上 `🏷️ [官网/权威]` 显著标识并**强制置顶排在第 1 位**。
2. **权威顶级域名加权（Authority Domain Boost）**：
   - 针对官方代码库（`github.com`, `apache.org` 等）、权威组织（`*.gov`, `*.edu`, `*.org`）、官方技术文档（`developer.mozilla.org`, `readthedocs.io` 等）及官方包托管平台（`npmjs.com`, `pypi.org`, `crates.io`），自动判定为高权威站点优先推荐。
3. **全引擎广告物理粉碎**：
   - 在浏览器 V8 上下文直接剔除包含 `.b_ad`, `.ec_wise_ad`, `.e-prom`, `.sponsor`, `#taw`, `[data-text-ad]` 等广告特征的 DOM 树，杜绝商业推广混入模型视野。
4. **指定 `officialOnly: true`**：
   - 若只需要官网链接（例如排查某个开源项目的真实主页或下载官方安装包），开启此参数即可自动过滤所有非官方博客或二次分发站。

### 零结果必须说清「被拦」还是「真没有」

搜索零结果是最容易被误读的场景：**「未找到结果」不等于关键词搜不到**，很可能是反爬验证码或网络不可达。因此 `browser_use(action: "search")` 在零结果时不再输出统一话术，而是逐引擎交代真实原因：

```
⚠️ 没有拿到任何结果，但这不等于「搜不到」——各引擎实际回报：
    · baidu — 人机验证/反爬拦截：百度安全验证（页面被重定向到验证页 https://wappass.baidu.com/...）
    · sogou — 人机验证/反爬拦截：搜狗反爬拦截
    · google — 网络不可达：浏览器网络错误（ERR_CONNECTION_TIMED_OUT）
诊断：2 个引擎被人机验证/反爬拦截，1 个网络不可达。
```

配套的三条硬机制：

1. **拦截识别覆盖真实验证页**：URL 特征（`wappass.baidu.com`、`/antispider/`、`qcaptcha.so.com`、`google.com/sorry`）优先于正文关键词，另加 Chrome 错误页（`ERR_CONNECTION_TIMED_OUT` / 无法访问此网站）与验证码控件探测；引擎自述「没有找到相关结果」时才归为**真的没结果**。
2. **搜索引擎健康自检（带缓存）**：对每个引擎域名做 TCP 可达性探测，并记住近期被拦截的引擎。非首选引擎若确认不可达/刚被拦，直接跳过并在原因中标注，不再为四个境外引擎各白等一次 6 秒超时（一次搜索可省 20~40 秒）。
3. **搜索互斥，杜绝并发串味**：所有搜索共用一个 `window.name` 标记的后台 worker 标签页（跨导航存活，不再每次新开标签页导致泄漏），并由进程内队列 + 跨进程文件锁串行化——并发搜索不会互相踩页面导致结果串味或误报「无结果」。

相关环境变量：

| 变量                     | 默认  | 作用                                             |
| :----------------------- | :---- | :----------------------------------------------- |
| `DP_ENGINE_HEALTH_TTL`   | `600` | 引擎可达性探测缓存秒数（0 = 每次都探）           |
| `DP_ENGINE_BLOCK_TTL`    | `900` | 被拦截引擎的冷却秒数（冷却期内非首选时直接跳过） |
| `DP_SEARCH_LOCK_TIMEOUT` | `90`  | 搜索文件锁最长等待秒数（超时放弃加锁，避免卡死） |
| `DP_SEARCH_LOCK_STALE`   | `120` | 超过该秒数的锁视为残留锁并被清理                 |

调用示例：

```json
{
	"query": "DrissionPage CDP 常见报错解决 site:github.com",
	"engine": "bing",
	"limit": 5
}
```

## 交互工具：`browser_use`

AI 可以直接使用原生 tool call 控制常驻浏览器（含搜索）：

| 动作 `action`       | 关键参数                                                                                            | 说明                                                                                                                |
| :------------------ | :-------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------------------------------------------------------ |
| `search`            | `query`(或 `text`), `engine?`, `timeRange?`, `page?`, `fetchTopContent?`, `limit?`, `officialOnly?` | 执行真实浏览器搜索并直接提取自然搜索结果（原 `browser_search` 能力全部并入此动作）                                  |
| `read_page`         | `url?`, `maxChars?`                                                                                 | 阅读器模式提取网页纯净正文与核心代码块，过滤所有噪音与广告；支持 HTML 表格转 Markdown、代码块语法高亮（极省 Token） |
| `open`              | `url`                                                                                               | 在当前标签页打开网址（自动补齐 `https://`）                                                                         |
| `new`               | `url`                                                                                               | 新建标签页并打开网址                                                                                                |
| `tabs`              | -                                                                                                   | 列出所有标签页（含序号、标题、网址及当前激活状态）                                                                  |
| `switch`            | `target`                                                                                            | 按序号（如 `"2"`）、标题或网址片段切换标签页                                                                        |
| `close`             | `target?`                                                                                           | 关闭标签页（默认当前激活页）                                                                                        |
| `snapshot`          | `interactiveOnly?`                                                                                  | 获取页面结构快照；`interactiveOnly: true` 时仅返回带序号的交互元素                                                  |
| `click`             | `target`, `byJs?`                                                                                   | 点击元素（可传快照序号 `"3"`、文本 `"Sign in"` 或 CSS 选择器）                                                      |
| `input`             | `target`, `text`                                                                                    | 清空并输入文本                                                                                                      |
| `select`            | `target`, `option`                                                                                  | 下拉框选择（按选项文本、值或序号）                                                                                  |
| `check` / `uncheck` | `target`                                                                                            | 勾选 / 取消勾选复选框或单选框                                                                                       |
| `type`              | `text`                                                                                              | 向当前获得焦点的元素直接打字                                                                                        |
| `press`             | `key`                                                                                               | 触发按键或快捷键（如 `"Enter"`、`"ctrl+a"`、`"Escape"`）                                                            |
| `hover`             | `target`                                                                                            | 鼠标悬停在指定元素上                                                                                                |
| `scroll`            | `scroll`                                                                                            | 页面滚动：`"top"`、`"bottom"`、`"up"`、`"down"` 或像素值                                                            |
| `wait`              | `seconds`                                                                                           | 等待指定秒数                                                                                                        |
| `js` / `jsx`        | `code`                                                                                              | 执行 JavaScript 代码或获取表达式值                                                                                  |
| `console`           | `level?`, `clear?`, `limit?`, `query?`                                                              | 查看当前标签页控制台日志（自动捕获 `log`/`warn`/`error` 与未捕获异常，支持按级别过滤与清空）                        |
| `screenshot`        | `path?`, `fullPage?`                                                                                | 截取页面截图（支持 fullPage 长图）                                                                                  |
| `quit`              | -                                                                                                   | 关闭常驻浏览器窗口，结束当前自动化会话                                                                              |

## 典型对话示例

- _“帮我查一下 Python 3.13 去除 GIL 的官方 PEP 进展”_  
  → AI 调用 `browser_use(action: "search", query: "Python 3.13 free threaded GIL PEP")`  
  → 2 秒内直接返回精简无广告的自然结果列表与官方链接。

- _“帮我去 GitHub 搜索热门的 DrissionPage 库并查看正文详情”_  
  → AI 调用 `browser_use(action: "search", query: "DrissionPage github repo", limit: 3)` 获取候选 URL  
  → AI 调用 `browser_use(action: "read_page", url: "https://github.com/g1879/DrissionPage")` 极速提取干净 README 正文（零垃圾代码与广告，仅消耗约 1,500 tokens）。

- _“看看刚才打开的页面为什么报错，控制台输出了什么”_  
  → AI 调用 `browser_use(action: "console", level: "error")`  
  → 立即获取当前网页捕获到的所有未捕获异常（Uncaught Exception）、Promise Rejection 与 `console.error` 输出及文件堆栈。
