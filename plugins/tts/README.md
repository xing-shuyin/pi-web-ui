# 多源通用语音合成插件 (TTS)

将 **字节豆包大模型语音** 与 **DeepSeek 语音** 注册到系统统一 TTS 中心。网页播报、QQ 自动语音回复和其他工具共用引擎与音色目录；内置 Chrome 伴侣扩展用于同步双平台凭据。

> 🛡️ **重要提示：关于 DeepSeek 防风控伪装模型与账号安全**：
>
> 1. **机制与风险分析**：DeepSeek 官方未开放独立的纯文本 TTS 合成 API。旧版插件由于每次临时新建会话且秒删会话，并附带脚本特征标头，极易被官方反作弊风控判定并封号。
> 2. **v1.4.0 全面防风控改造措施**：
>    - **彻底伪装真实 Chrome Headers**：移除了所有第三方脚本特征，对齐 Chrome 133 最新标准标头与 `sec-ch-ua` 指纹；
>    - **专属长期会话复用（Session Reuse）**：不再新建与秒删会话，自动建立并长期复用一个专属语音桥接会话，完全契合正常用户的多轮对话行为；
>    - **自然多样化 Prompt**：采用多变的人性化提问模板随机轮换，避免单一文本聚类；
>    - **人性化防抖与排队锁**：限制调用间歇，防止高频并发脉冲。
> 3. **使用建议**：
>    - 生产与大量长文本流式伴读强烈推荐使用 **豆包语音**（支持火山引擎 API Key 商业通道，正规稳定且绝对免封）或**服务器系统语音**；
>    - 若使用 DeepSeek 音色，改造后安全性已大幅提升，但鉴于其属于逆向接口，仍建议配合不重要的测试小号使用。

## 统一 TTS 中心

引擎在插件服务端通过 `host.tts.registerEngine()` 注册，无需打开插件页面。网页「设置 → 声音与语音」、本插件试听面板、QQ 语音设置都从中心读取引擎与音色。`builtin` 系统引擎由宿主提供，插件注册 `doubao-tts` 与 `deepseek-tts`。

AI `tts` 工具支持 `action: "list"` 查询全部引擎，带 `engine` 查询对应音色；合成时可选择系统或其他插件注册的引擎。旧 `doubao` / `deepseek` 参数继续可用。卸载插件会撤销引擎注册并取消进行中的请求。接口与迁移说明见 [`docs/architecture-tts.md`](../../docs/architecture-tts.md)。

## 特性亮点

1. **双平台顶级语音聚合**：
   - **豆包大模型语音**：阳光阿辰/阳光青年、磁性俊宇、清爽男大、温柔桃子、阳光甜妹等优质角色音色（支持网页 Cookie 与火山引擎 API Key）；
   - **DeepSeek 官方语音**：白浪 Echo (明朗男声)、暗潮 Tide (低沉男声)、贝壳 Mira (活泼女声)、海星 Stella (甜美女声)。
2. **伴侣扩展双向同步**：
   - 配套扩展同时支持 `doubao.com` 与 `chat.deepseek.com`，在任一网页中点开扩展图标，一键将当前登录态同步到本地。
3. **系统内置语音无缝切换**：
   - 在 **设置 -> 声音与语音 -> 语音引擎** 下拉框中，可直接在「系统语音」、「豆包语音」、「DeepSeek 语音」以及其他已注册引擎之间自由切换；
   - 消息卡片右下角的小喇叭、后台提示音、流式边打字边朗读全部原生生效。
4. **流式分句播放队列**：
   - 网页按句播放生成的音频；中心按引擎统一排队，停止朗读时取消生成并释放音频资源。
5. **AI 工具支持**：
   - 提供 `tts` 工具，AI 可查询中心引擎、选择音色并生成音频文件，扩展名根据引擎返回格式确定。

## 快速安装与配置

### 1. 伴侣扩展加载（30秒完成）

1. Chrome / Edge 打开 `chrome://extensions` 并开启右上角「开发者模式」；
2. 在 pi-web-ui 左侧菜单进入「语音合成 (TTS)」面板，点击 **【📂 在电脑中定位扩展目录】**；
3. 将弹出的 `extension` 文件夹直接拖进浏览器的扩展页面中即可。

### 2. 同步凭据

- 在浏览器打开 [doubao.com](https://www.doubao.com) 或 [chat.deepseek.com](https://chat.deepseek.com) 并登录；
- 点击浏览器右上角扩展栏的 🔊 图标，点击 **【🚀 一键提取全部】** 即可同步。

## 本地 HTTP 接口说明

- `POST /plugins-api/tts/sync-credentials`：接收并持久化豆包 Cookie 与 DeepSeek token。
- `POST /plugins-api/tts/speak`：兼容入口，调用统一中心合成并返回 base64 音频；`engine` 接受注册 ID，也兼容 `doubao` / `deepseek`。网页统一入口为 `/api/tts/engines`、`/api/tts/voices` 和 `/api/tts/synthesize`。
- `POST /plugins-api/tts/open-folder`：定位扩展所在目录。
- `GET /plugins-api/tts/download-extension`：下载扩展 ZIP 压缩包。
