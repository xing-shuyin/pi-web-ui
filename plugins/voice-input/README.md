# 语音与拍照输入插件（voice-input）

输入框旁两个按钮：🎤 点一下说话，浮层里有两个收尾：「填入输入框」（进草稿，你补一句再发送）与「直接发送」（发给当前对话，不需要编辑）；
📷 打开摄像头拍一张，照片作为附件进输入框（手机上也可以直接调起系统相机）。

此外还给 AI 一个 `transcribe_audio` 工具：工作区里的会议录音、语音备忘，AI 可以直接转成文字来读。

## 三条链路（可主动选，默认自动降级）

1. **浏览器原生识别**（免费零配置）：Chrome / Edge 用 Web Speech API 实时听写，中英文都可。**要联网**。
2. **本地 Whisper**（服务端，一键安装）：浮层里的「一键安装本地 Whisper」，
   服务端自动装运行时 + 下载模型（tiny 约 150MB / base 约 290MB / small 约 500MB 最准），以后录音不出本机、不要 key 也能转写。
   录音是浏览器现场编码的 16k 单声道 WAV（AudioWorklet），服务端无需装 ffmpeg。
3. **远端转写**（服务端，需配接口）：Firefox / Safari 等没有 Web Speech API，或识别出错时，
   录音 POST 到服务端的 `/plugins-api/voice-input/transcribe`，
   服务端转发给 OpenAI 兼容的 `/audio/transcriptions` 接口（Whisper）。

`auto` 模式（默认）：点 🎤 先试浏览器识别，失败/不支持再依次降级到本地 Whisper → 远端接口。

### 不想等联网失败：直接点名要哪条链路

「转写引擎」选 `local` 或 `remote` 后，点 🎤 **直接**走它：选 `local` 且本地已装就马上录音，
还没装则当场弹一键安装（不用先干等几秒浏览器语音服务报错）；选 `remote` 则直接录音发远端，
没配接口时明确告诉你去哪儿填。

录音浮层（含浏览器识别中与录音中）还有一个常驻的**「切换识别方式」**按钮，随时在
浏览器联网识别 / 本地 Whisper / 远端接口之间切换，选完写回插件设置（下次点 🎤 直接用这一档）。
注意：该切换不会即时刷新已打开的设置页，⚙ 面板里看到的是下次打开时的值。

## 拍照（📷）

点 📷 弹出取景面板，按快门就把照片放进输入框附件（可以连拍多张），补齐你要说的话再发。

- **默认走摄像头**（`getUserMedia`）：面板里可切前置/后置（设备只有一个摄像头时不显示切换按钮）。
- **打不开就换条路**：非安全上下文 / 设备没摄像头 / 权限被拒时，面板会直说明原因，
  并给一个「用系统相机 / 选图片」按钮 —— 手机直接调起系统相机 App，桌面退化成选图。**这条路不需要任何权限**。
- 照片按最长边 1568px 压成 JPEG、并保证 ≤2MB（与服务端粘贴图片硬上限一致），
  所以它走的完全是**粘贴图片那条链路**，不会往上下文里塞原图。
- 摄像头只在面板开着时占用，关面板 / 插件反激活即停流（指示灯会灭）。

## 安装

设置面板 → 界面插件 → 插件市场 → 找到「语音输入」点安装；或：

```bash
pi-web-ui install xing-shuyin/pi-web-ui/plugins/voice-input
```

`view: false`：没有独立视图 tab，只在输入框动作区多 🎤 与 📷 两个按钮
（设置 → 界面布局里可隐藏/排序）。

`permissions` 里的 `fs:read` 是 `transcribe_audio` 读工作区音频文件所需的最小读权限
（只能读工作区内的文件，越界拒绝）。更新到 0.2.0 时宿主会提示一次「能力清单变了」，属正常安全提示。

## 配置（设置面板 → 界面插件 → 语音输入）

| 项             | 说明                                                                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 识别语言       | 默认 `zh-CN`；浏览器识别与 Whisper `language` 共用                                                                                       |
| 服务端转写降级 | 默认开；**只管 `auto` 档的兵底**——显式选了 `local`/`remote` 时不拦你（见上文）                                                           |
| 转写引擎       | 默认 `auto`（先浏览器识别，再本地 → 远端降级）；`local` 点 🎤 直接本地（没装先带你装）；`remote` 只用远端                                |
| 模型下载源     | 留空 = 官方 `huggingface.co`；国内直连超时填 `https://hf-mirror.com`。也认环境变量 `HF_ENDPOINT`                                         |
| 本地模型       | 默认 `base`（中文更准，约 290MB）；`tiny` 更小更快（约 150MB）；`small` 最准（约 500MB，CPU 转写慢 3~4 倍）。转写时常驻内存约 1GB        |
| 转写接口基址   | OpenAI 兼容基址，如 `https://api.openai.com/v1`；留空 = 没配远端转写                                                                     |
| 转写接口密钥   | 存在 `<dataDir>/plugins/voice-input/storage.json`，**不下发浏览器**                                                                      |
| 转写模型       | 默认 `whisper-1`                                                                                                                         |
| 给 AI 转写工具 | 默认开；注册 `transcribe_audio` 给 AI 用。关掉这里即从 AI 的工具表里下架；此外宿主设置 →「工具」页的「注册的 AI 工具」分组里也能单独关它 |

本地模型文件放在 `<dataDir>/plugins/voice-input/whisper-cache/`（卸载插件即删除）；
设置面板目前没有按钮，**安装/卸载入口在 🎤 浮层里**（没装时会主动提示）。
卸载模型只删权重（`DELETE /plugins-api/voice-input/local`），运行时（node_modules）留着，重装秒级。

第三方兼容接口（本地 Whisper 服务、代理等）只要暴露
`POST {base}/audio/transcriptions`（multipart `file`/`model`/`language`）
就能用。

## 给 AI 的转写工具（transcribe_audio）

AI 自己听不了音频，所以本插件给它一个工具：把一个**工作区内**的音频文件转成文字。

```js
transcribe_audio({ path: "notes/standup.m4a", lang: "zh-CN" });
```

- **WAV**：本地 Whisper 能直接解码（不需要 ffmpeg）。
- **mp3 / m4a / ogg / webm / flac**：本地引擎**解不了**（只有 WAV 解码器），
  必须在设置里配好「转写接口基址 / 密钥」走远端；没配时工具会明确告诉 AI 这两条出路，而不是丢一个 415。
- 本地单次上限约 8 分钟 / 15MB（超了请分段）；远端上限 25MB。
- 只能读工作区内的文件，工作区外会拒绝（先把那个目录加为工作区根）。

## Edge сpeech 识别失败排障

点了 🎤 没反应 / 直接报错，先对号入座（现在浮层会直接告诉你是哪一种）：

1. **页面是 `http://<局域网IP>:8787` 打开的**（最常见）：非安全上下文，Edge 直接禁用语音识别+麦克风。
   改用 `http://localhost:8787` 或 `http://127.0.0.1:8787` 打开。
2. **network 错误**：Edge 语音识别要联网，代理 / VPN / 公司网关可能拦了语音服务。
   插件会自动切服务端录音；网络修好前直接用服务端录音即可。
3. **not-allowed**：麦克风权限被拒。点地址栏左侧 🔒 图标 → 麦克风 → 允许 → 刷新页面。
4. **浏览器识别反复静默断句**：浮层里有「改用服务端录音」按钮，一键绕过。

以上都走不通（比如 Firefox / iOS Safari 根本没有语音识别）：浮层里的
「一键安装本地 Whisper」是最省事的路，不用买 key、不用配接口。

## 隐私

- 浏览器识别：音频留在本机与浏览器语音服务之间（Chrome 走 Google 服务），不经过 pi-web-ui 服务端。
- 本地 Whisper：音频不出本机，模型跑在服务端 CPU 上，不落盘（内存转写）。
- 远端转写：录音只转发到你自己配的转写接口，不落盘（内存转发，失败不留文件）。
- 拍照：画面只在你的浏览器里取帧、压成 JPEG，**不经过服务端处理**；
  插件不保存任何照片文件 —— 照片就活在输入框附件里，发不发、发哪张都由你决定。
- 转写文件：AI 调 `transcribe_audio` 时会读工作区里的那个音频文件（只读，不复制、不落盘），
  本地转写在内存里完成，只有远端转写才把字节发给你自己配的接口。

## 兼容性

- 需要宿主 `window.__piWebUiHost.compose / onUiAction`（插件宿主 API v2+，
  manifest `apiVersion: 2` 会先拦住旧版 pi-web-ui）。
- 移动端：手机 Chrome 可用；iOS Safari 走服务端降级（需配转写接口 + 麦克风权限）。
- 拍照需要安全上下文（`localhost` / `127.0.0.1` / https）；非安全上下文下面板会自动退到
  「用系统相机 / 选图片」那条不需要权限的路。
