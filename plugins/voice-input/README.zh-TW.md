# 語音與拍照輸入外掛（voice-input）

輸入框旁兩個按鈕：🎤 點一下說話，浮層裡有兩個收尾：「填入輸入框」（進草稿，你補一句再發送）與「直接傳送」（發給當前對話，不需要編輯）；
📷 開啟攝像頭拍一張，照片作為附件進輸入框（手機上也可以直接調起系統相機）。

此外還給 AI 一個 `transcribe_audio` 工具：工作區裡的會議錄音、語音備忘，AI 可以直接轉成文字來讀。

## 三條鏈路（可主動選，預設自動降級）

1. **瀏覽器原生識別**（免費零配置）：Chrome / Edge 用 Web Speech API 即時聽寫，中英文都可。**要聯網**。
2. **本地 Whisper**（服務端，一鍵安裝）：浮層裡的「一鍵安裝本地 Whisper」，
   服務端自動裝執行時 + 下載模型（tiny 約 150MB / base 約 290MB / small 約 500MB 最準），以後錄音不出本機、不要 key 也能轉寫。
   錄音是瀏覽器現場編碼的 16k 單聲道 WAV（AudioWorklet），服務端無需裝 ffmpeg。
3. **遠端轉寫**（服務端，需配介面）：Firefox / Safari 等沒有 Web Speech API，或識別出錯時，
   錄音 POST 到服務端的 `/plugins-api/voice-input/transcribe`，
   服務端轉發給 OpenAI 相容的 `/audio/transcriptions` 介面（Whisper）。

`auto` 模式（預設）：點 🎤 先試瀏覽器識別，失敗/不支援再依次降級到本地 Whisper → 遠端介面。

### 不想等聯網失敗：直接點名要哪條鏈路

「轉寫引擎」選 `local` 或 `remote` 後，點 🎤 **直接**走它：選 `local` 且本地已裝就馬上錄音，
還沒裝則當場彈一鍵安裝（不用先乾等幾秒瀏覽器語音服務報錯）；選 `remote` 則直接錄音發遠端，
沒配介面時明確告訴你去哪兒填。

錄音浮層（含瀏覽器識別中與錄音中）還有一個常駐的**「切換識別方式」**按鈕，隨時在
瀏覽器聯網識別 / 本地 Whisper / 遠端介面之間切換，選完寫回外掛設定（下次點 🎤 直接用這一檔）。
注意：該切換不會即時重新整理已開啟的設定頁，⚙ 面板裡看到的是下次開啟時的值。

## 拍照（📷）

點 📷 彈出取景面板，按快門就把照片放進輸入框附件（可以連拍多張），補齊你要說的話再發。

- **預設走攝像頭**（`getUserMedia`）：面板裡可切前置/後置（裝置只有一個攝像頭時不顯示切換按鈕）。
- **打不開就換條路**：非安全上下文 / 裝置沒攝像頭 / 許可權被拒時，面板會直說明原因，
  並給一個「用系統相機 / 選圖片」按鈕 —— 手機直接調起系統相機 App，桌面退化成選圖。**這條路不需要任何許可權**。
- 照片按最長邊 1568px 壓成 JPEG、並保證 ≤2MB（與服務端貼上圖片硬上限一致），
  所以它走的完全是**貼上圖片那條鏈路**，不會往上下文裡塞原圖。
- 攝像頭只在面板開著時佔用，關面板 / 外掛反啟用即停流（指示燈會滅）。

## 安裝

設定面板 → 介面外掛 → 外掛市場 → 找到「語音輸入」點安裝；或：

```bash
pi-web-ui install xing-shuyin/pi-web-ui/plugins/voice-input
```

`view: false`：沒有獨立檢視 tab，只在輸入框動作區多 🎤 與 📷 兩個按鈕
（設定 → 介面佈局裡可隱藏/排序）。

`permissions` 裡的 `fs:read` 是 `transcribe_audio` 讀工作區音訊檔案所需的最小讀許可權
（只能讀工作區內的檔案，越界拒絕）。更新到 0.2.0 時宿主會提示一次「能力清單變了」，屬正常安全提示。

## 配置（設定面板 → 介面外掛 → 語音輸入）

| 項             | 說明                                                                                                                                     |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 識別語言       | 預設 `zh-CN`；瀏覽器識別與 Whisper `language` 共用                                                                                       |
| 服務端轉寫降級 | 預設開；**只管 `auto` 檔的兵底**——顯式選了 `local`/`remote` 時不攔你（見上文）                                                           |
| 轉寫引擎       | 預設 `auto`（先瀏覽器識別，再本地 → 遠端降級）；`local` 點 🎤 直接本地（沒裝先帶你裝）；`remote` 只用遠端                                |
| 模型下載源     | 留空 = 官方 `huggingface.co`；國內直連超時填 `https://hf-mirror.com`。也認環境變數 `HF_ENDPOINT`                                         |
| 本地模型       | 預設 `base`（中文更準，約 290MB）；`tiny` 更小更快（約 150MB）；`small` 最準（約 500MB，CPU 轉寫慢 3~4 倍）。轉寫時常駐記憶體約 1GB      |
| 轉寫介面基址   | OpenAI 相容基址，如 `https://api.openai.com/v1`；留空 = 沒配遠端轉寫                                                                     |
| 轉寫介面金鑰   | 存在 `<dataDir>/plugin-data/voice-input/storage.json`，**不下發瀏覽器**                                                                  |
| 轉寫模型       | 預設 `whisper-1`                                                                                                                         |
| 給 AI 轉寫工具 | 預設開；註冊 `transcribe_audio` 給 AI 用。關掉這裡即從 AI 的工具表裡下架；此外宿主設定 →「工具」頁的「註冊的 AI 工具」分組裡也能單獨關它 |

本地模型檔案放在 `<dataDir>/plugins/voice-input/whisper-cache/`（解除安裝外掛即刪除）；
設定面板目前沒有按鈕，**安裝/解除安裝入口在 🎤 浮層裡**（沒裝時會主動提示）。
解除安裝模型只刪權重（`DELETE /plugins-api/voice-input/local`），執行時（node_modules）留著，重灌秒級。

第三方相容介面（本地 Whisper 服務、代理等）只要暴露
`POST {base}/audio/transcriptions`（multipart `file`/`model`/`language`）
就能用。

## 給 AI 的轉寫工具（transcribe_audio）

AI 自己聽不了音訊，所以本外掛給它一個工具：把一個**工作區內**的音訊檔案轉成文字。

```js
transcribe_audio({ path: "notes/standup.m4a", lang: "zh-CN" });
```

- **WAV**：本地 Whisper 能直接解碼（不需要 ffmpeg）。
- **mp3 / m4a / ogg / webm / flac**：本地引擎**解不了**（只有 WAV 解碼器），
  必須在設定裡配好「轉寫介面基址 / 金鑰」走遠端；沒配時工具會明確告訴 AI 這兩條出路，而不是丟一個 415。
- 本地單次上限約 8 分鐘 / 15MB（超了請分段）；遠端上限 25MB。
- 只能讀工作區內的檔案，工作區外會拒絕（先把那個目錄加為工作區根）。

## Edge сpeech 識別失敗排障

點了 🎤 沒反應 / 直接報錯，先對號入座（現在浮層會直接告訴你是哪一種）：

1. **頁面是 `http://<區域網IP>:8787` 開啟的**（最常見）：非安全上下文，Edge 直接停用語音識別+麥克風。
   改用 `http://localhost:8787` 或 `http://127.0.0.1:8787` 開啟。
2. **network 錯誤**：Edge 語音識別要聯網，代理 / VPN / 公司閘道器可能攔了語音服務。
   外掛會自動切服務端錄音；網路修好前直接用服務端錄音即可。
3. **not-allowed**：麥克風許可權被拒。點位址列左側 🔒 圖示 → 麥克風 → 允許 → 重新整理頁面。
4. **瀏覽器識別反覆靜默斷句**：浮層裡有「改用服務端錄音」按鈕，一鍵繞過。

以上都走不通（比如 Firefox / iOS Safari 根本沒有語音識別）：浮層裡的
「一鍵安裝本地 Whisper」是最省事的路，不用買 key、不用配介面。

## 隱私

- 瀏覽器識別：音訊留在本機與瀏覽器語音服務之間（Chrome 走 Google 服務），不經過 pi-web-ui 服務端。
- 本地 Whisper：音訊不出本機，模型跑在服務端 CPU 上，不落盤（記憶體轉寫）。
- 遠端轉寫：錄音只轉發到你自己配的轉寫介面，不落盤（記憶體轉發，失敗不留檔案）。
- 拍照：畫面只在你的瀏覽器裡取幀、壓成 JPEG，**不經過服務端處理**；
  外掛不儲存任何照片檔案 —— 照片就活在輸入框附件裡，發不發、發哪張都由你決定。
- 轉寫檔案：AI 調 `transcribe_audio` 時會讀工作區裡的那個音訊檔案（只讀，不復制、不落盤），
  本地轉寫在記憶體裡完成，只有遠端轉寫才把位元組發給你自己配的介面。

## 相容性

- 需要宿主 `window.__piWebUiHost.compose / onUiAction`（外掛宿主 API v2+，
  manifest `apiVersion: 2` 會先攔住舊版 pi-web-ui）。
- 移動端：手機 Chrome 可用；iOS Safari 走服務端降級（需配轉寫介面 + 麥克風許可權）。
- 拍照需要安全上下文（`localhost` / `127.0.0.1` / https）；非安全上下文下面板會自動退到
  「用系統相機 / 選圖片」那條不需要許可權的路。
