# README 實錄素材

這些素材錄自本地倉庫已有構建執行的 pi-web-ui，使用獨立服務、獨立配置與 Color Notes 示例 Git 專案。沒有讀取使用者現有對話、憑據或工作目錄，也未呼叫模型。官方圖示使用倉庫自帶素材。錄製中顯示的圓形指示器用於標明真實滑鼠位置。

| 檔案                   | 內容                                                                      | 尺寸     | 時長       |
| ---------------------- | ------------------------------------------------------------------------- | -------- | ---------- |
| `hero.svg`             | 透明底封面，適用於淺色頁面                                                | 1200×360 | 靜態       |
| `hero-dark.svg`        | 透明底封面，適用於深色頁面                                                | 1200×360 | 靜態       |
| `workspace.gif`        | 預覽示例 README、檢視實際 Git diff、在內建終端執行 `node src/palette.mjs` | 1080×675 | 約 11.5 秒 |
| `canvas.gif`           | 實際執行五節點本地文本流程，兩路轉換後彙總輸出                            | 1080×675 | 約 8.7 秒  |
| `showcase.mp4`         | 工作區與畫布兩段操作連續播放                                              | 1440×900 | 約 20.2 秒 |
| `workspace-poster.png` | 工作區錄屏中的檔案預覽幀                                                  | 1440×900 | 靜態       |
| `canvas-poster.png`    | 畫布錄屏中的已完成流程幀                                                  | 1440×900 | 靜態       |

GIF 為 6 fps，MP4 為 H.264、24 fps、無音軌。操作經過剪輯和時間壓縮，不用於衡量效能；影片中的節點輸出來自確定性本地文本轉換，不是 AI 推理結果。錄屏以真實介面貼邊展示，不把頁面背景、裝飾外框或標題烘焙進媒體，便於在深淺色頁面中引用。

GIF 可直接引用在 GitHub Markdown 中。MP4 提供清晰版播放/下載；專案 README 中使用普通連結，未上傳至 GitHub 附件服務。

中英文 README 使用 `<picture>` 與 `prefers-color-scheme` 為封面選擇深淺配色，普通 `<img>` 回退到 `hero.svg`。兩份 SVG 均為透明底，不依賴自定義 CSS。

## 重新生成錄屏素材

需要 Node.js、FFmpeg 與原始的 6 fps PNG 錄屏。錄製目錄內應有 `workspace-frames/` 和 `canvas-frames/`，檔案從 `00000.png` 開始連續編號：

```sh
node assets/readme/build-media.mjs <錄製目錄>
```

生成器直接從原始畫面生成 GIF、靜態幀與 MP4，輸出到本目錄。不要使用帶舊漸變底板的合成幀作為輸入。
