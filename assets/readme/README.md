# README 实录素材

这些素材录自本地仓库已有构建运行的 pi-web-ui，使用独立服务、独立配置与 Color Notes 示例 Git 项目。没有读取用户现有对话、凭据或工作目录，也未调用模型。官方图标使用仓库自带素材。录制中显示的圆形指示器用于标明真实鼠标位置。

| 文件                   | 内容                                                                      | 尺寸     | 时长       |
| ---------------------- | ------------------------------------------------------------------------- | -------- | ---------- |
| `hero.svg`             | 透明底封面，适用于浅色页面                                                | 1200×360 | 静态       |
| `hero-dark.svg`        | 透明底封面，适用于深色页面                                                | 1200×360 | 静态       |
| `workspace.gif`        | 预览示例 README、查看实际 Git diff、在内置终端运行 `node src/palette.mjs` | 1080×675 | 约 11.5 秒 |
| `canvas.gif`           | 实际运行五节点本地文本流程，两路转换后汇总输出                            | 1080×675 | 约 8.7 秒  |
| `showcase.mp4`         | 工作区与画布两段操作连续播放                                              | 1440×900 | 约 20.2 秒 |
| `workspace-poster.png` | 工作区录屏中的文件预览帧                                                  | 1440×900 | 静态       |
| `canvas-poster.png`    | 画布录屏中的已完成流程帧                                                  | 1440×900 | 静态       |

GIF 为 6 fps，MP4 为 H.264、24 fps、无音轨。操作经过剪辑和时间压缩，不用于衡量性能；视频中的节点输出来自确定性本地文本转换，不是 AI 推理结果。录屏以真实界面贴边展示，不把页面背景、装饰外框或标题烘焙进媒体，便于在深浅色页面中引用。

GIF 可直接引用在 GitHub Markdown 中。MP4 提供清晰版播放/下载；项目 README 中使用普通链接，未上传至 GitHub 附件服务。

中英文 README 使用 `<picture>` 与 `prefers-color-scheme` 为封面选择深浅配色，普通 `<img>` 回退到 `hero.svg`。两份 SVG 均为透明底，不依赖自定义 CSS。

## 重新生成录屏素材

需要 Node.js、FFmpeg 与原始的 6 fps PNG 录屏。录制目录内应有 `workspace-frames/` 和 `canvas-frames/`，文件从 `00000.png` 开始连续编号：

```sh
node assets/readme/build-media.mjs <录制目录>
```

生成器直接从原始画面生成 GIF、静态帧与 MP4，输出到本目录。不要使用带旧渐变底板的合成帧作为输入。
